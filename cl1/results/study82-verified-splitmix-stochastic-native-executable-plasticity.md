**128 unique fresh, genuinely different original seeded CIL code genotypes** (`5_500_000..5_500_127`), each with exact identical executable graph across 4 arms (source3/source8 × mutation enabled/disabled): **512 original native worlds** and **12,288 original post-epoch SHA256 whole-state snapshots**, all complete and exactly Rust-replayed. The 4/128 is **coexistence**, not demonstrated benefit of mutation, endogenous energetic sufficiency, adaptive source response or repair of damaged code. Native code mutation is an actor-executed CIL instruction selected via a source-committed investigator-designed grammar; the native VM supplies the generic edit affordance. Its existence is scientifically distinguishable from a host `PatchEdge`, but is not yet spontaneous discovery of a repair policy. Compute pool and +8 epoch credit input are explicitly external environmental physics, not energy the organism creates.

### Why this is a real but bounded advance

The earlier technical problem was that random programs very rarely combined actual functioning source Read→Write with real native Draw and any effective code editing. This new distinct prospective cohort **directly observes** all three in 4/128 original genotypes, with exact actor PC, code edge and tainted output ancestry; low/high native executable edits are present in many more genotypes. However there was no lesion, no functional restoration after damage, no survival selection, no child inheriting a maintained function and no multi-component closure. Moreover a successful edit may destroy previously effective code. That causal direction requires the original matched edit-disabled arms, evaluated separately in the registered **retrospective** Study83 rather than re-interpreting this preregistered survey.

**Decision:** This supports feasibility of stochastic native structural plasticity and source-aware function/energy coexistence under specific external laws. It does **not** satisfy CL-1 closure or cyberlife.
