Children start with zero registers. A born child whose PC4.next=24 **actually incurs the extra CIL loop** before continuing to the same self-replicating machinery; a child whose PC4.next=5 skips that loop. Both retain real native Read7→Write9 with the expected source input. The test steps the native VM one charged instruction at a time and checks **the child code at the instant of actual birth**, the parent executable site at that moment, actor-PC native code-edit events, all28 native graph copy nodes, actual same-actor Draw before each Launch, and total compute inventory `initial7000 - chargedAttempts`. Native offspring branch from surviving parents and grandchildren reproduce.

Two prespecified human controls: (a) rewriting only the seed's PC8 mutation opcode to a charged inert Const produces children that all retain fast edge5 and **zero native mutation events**; this *uses a different initial genotype*, so it cannot estimate spontaneous mutation selection; (b) eliminating the single starting common pool prevents all native descendants and yields genuine DrawDeferred(400). Every CIL seed and shared-cell toggling rule is **human authored**, and both source-input variants are paired environments, not independent ecological genotypes.

The combined VM now supports **branching native self-copy**, **genuine inherited mutation at a functionally executed edge**, **actual descendant variation in consumed native instruction count**, and **real finite shared-resource accounting**. This is stronger than Stage100's mutation of a dormant fitness-neutral node, or Study101's manually prewritten founder competition.
