## Decision: diagnose native graph assembly mechanism directly, separately from natural emergence

Study45 found most native launched child code graphs have open outgoing control-flow edges relative to their executable graph. Before wasting further independent worlds tuning random grammar, perform a **small explicitly scripted, non-ecological mechanism calibration** to establish that existing CIL `GraphCopyNode → GraphSetNext → GraphLaunch` can (or cannot) produce a native child that successfully executes a copied shared-cell Write with a locally closed edge. This is a *host-written builder demonstration*, thus **zero new independent ecological worlds, no life/repair/reproduction claim**. Only after that should fresh stochastic ecologies test whether such capabilities can arise without a predefined assembly sequence.
