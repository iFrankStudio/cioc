## Mechanistic conclusion and next requirement

Native CIL can copy an original Write source node with correctly attributed events even without a purpose-built graph builder. The absence of functional native child output in the observed test is therefore **not solely due to inability to access Write code or due to source/destination register alias**. The immediate observed failure is **temporal compositionality**: after a native Write-source copy, the same actor did not perform a subsequent native GraphLaunch of that source graph, much less a graph-local control-flow edit sufficient for function.

Further blind seed volume or random opcode-weight tuning has limited explanatory value. A more informative independent prospective study should vary **generic executable-code graph topology** (random edge connectivity, branch locality or temporal program reuse) while preserving the unbiased native operation grammar and source provenance, then measure ordered native composition separately from functional child output. No guaranteed-success code sequence, repair/reproduce opcode or organism-specific host reward may be introduced.
