The registered **0/256** strict four-arm endpoint has a 95% Wilson descriptive interval **[0, 0.014784]** for this one fixed generator only. It is an **exposure-limited null**, not a measured universal cyberlife emergence rate. The observed individual reads demonstrate both code sources were accessible under the revised grammar, but don't establish they co-occurred in a single actor/read-to-add-to-write execution or generated the expected additive address.

Sham and exact unaltered graph2 reinjection had the same simulated state as untreated. All interventions were explicit external events. The zero-credit branch had no native CIL execution. The study does not evaluate endogenous repair or persistence in later temporal windows.

## Scientific interpretation and required next discrimination

A **single-source external-code-sensitive address** was previously shown in Study27 (2/192). Study28 found no supported *second read-mediated component* in those known cases, and Study29 introduced a different random grammar that technically exposes both source reads in some worlds, but the **strict two-component additive function still had zero fully paired witnesses**.

Next step is a separately marked post-result diagnostic using the same *fixed* Study29 world IDs and source revision. Count successful **both-source native reads by the same actor in one epoch**, versus later native `Add` and `CellWritten`; identify which stage of the ordinary CIL pathway is missing without retuning the existing outcome criterion. Any subsequent genuinely new prospective design must be registered before new independent seed runs and may not relabel its externally chosen generator as endogenous design.
