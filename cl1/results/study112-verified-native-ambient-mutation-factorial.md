## Strong causal boundary, limitations and next hypothesis

Within this frozen engineered substrate, permitting native, heritable function-changing code edits **does cause a beneficial reproductive opportunity in most original genotype parameterizations only when general public environmental compute supply repeats**. The new finding is a *causal interaction* among experimental VM laws and actual CIL code/offspring, **without an externally supplied organism fitness ranking or actor-targeted credits**. It is stronger than a cross-study comparison and survives true code-identity and mutation-only negative controls.

It is nevertheless a HUMAN-DESIGNED evolvable system: all original code (including the selfcopy loop, intended fast/slow functional branch and deterministic target-cell toggle) was authored by the experimenter, and all continuing compute is supplied by EXTERNAL world physics. Therefore **neither native self-sufficiency, unbiased random mutation, general Darwinian selection from arbitrary genomic variation, endogenous two-component organizational closure nor origin of cyberlife is demonstrated**. Resource competition is finite and the metric remains a fixed 16-epoch output. Reproducing this experiment under an unprescribed generic mutation source and selection among multiple lineages is the next scientific gate; blindly adding more seeds of this same hand-authored 28-node program would not prove spontaneous life.
