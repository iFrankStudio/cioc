## Verified functional calibration

The same initial world contained two nonempty CIL-created graph objects, both readable by the third process. The reader independently read each graph's instruction tag and wrote the sum into shared cell 90. The entire process design, including the two CIL construction programs and the reader, was provided by the investigator. Thus these are internally *executed* components, **not endogenously designed** organization.

| Matched branch | Registered output cell 90 | Observed |
| --- | ---: | ---: |
| Untreated control | 11 | 11 |
| Rejected sham graph0 deletion | 11 | 11 |
| External deletion graph1 | absent | absent |
| External deletion graph2 | absent | absent |
| External deletion both graphs | absent | absent |
| Delete graph1, externally inject same object before reader executes | 11 | 11 |
| Delete graph2, externally inject same object before reader executes | 11 | 11 |
| Delete graph2, externally inject altered code tag before read | 30 | 30 |
| Zero-credit | absent | absent |

The sham simulated states matched the untreated control; successful cell writes were attributed to actual internally charged reader instructions; every change to graph structure, credit inventory and positive-control restoration was explicit `Origin::External`. Each branch passed exact deterministic replay and independently checked final/snapshot hashes.

## What the result establishes

1. A concrete **source-content-sensitive** two-component information-processing observable exists in the CIL substrate.
2. Either externally targeted component loss prevents that reader output; the absence is not merely a change in how many graphs are stored.
3. Immediate explicit external same-object graph injection restores the capacity to produce the registered output under otherwise matched initialization; an externally altered code node predictably changes the output from 11 to 30.
4. This is **NOT** evidence of self-maintenance: the intervention occurs before the reader would encounter the missing graph, not after a function has been lost and internally recovered across separated windows. A trapped reader cannot simply be assumed to restart. No internally discovered assembly plan, source-tainted autonomous restoration, or persistent closed organization is shown.
