# CL-1 Study 10 — neutral executable ecology design proposal (NOT preregistered)

**Status:** methodological engineering design only. No Study-10 trial has been run, no seed-range registration made and no outcome threshold is fixed. This document must not be treated as a preregistration or positive scientific result.

## Motivation from the completed null-capable studies

Purely random 16–32 node CIL streams frequently fail before generic graph exchange is meaningfully possible. Study 08's 14-way grammar lacked `GraphGrantRead` (structurally excluded authorized cross-owner reads). Study 09 added grants and revocations, longer code and budgets, but **0/128** common pre-treatment worlds contained an eligible nonempty graph object. It is invalid to call absence of successful cross-owner exchange a meaningful test when the relevant substrate was never reached.

More random seeds with the same rapidly trapping distribution improve only a narrow probability estimate, not the ability to test the original CL-1 question.

## What a neutral opportunity scaffold may do

A next independent study may initialize the world with **generic, reliable information-manipulation opportunities** rather than raw uniformly random commands: each externally created source program can perform ordinary allocation, publish references into ordinary shared cells, grant and revoke reads, copy graph nodes and transfer ownership. All of those remain normal CIL operations paying normal resource costs; none are `REPAIR`, `REPRODUCE`, `FITNESS`, damage detection or preference selection.

Important attribution boundary: if the investigator writes instructions causing each process to create a graph and publish a handle, that act is **internally executed but externally scripted**. The resulting graph is *not* evidence of spontaneous invention of object construction. The null must include a matched world with the same scaffold but randomized later code and identical resources.

Possible subsequent instructions can be sampled from a bounded neutral grammar with validated registers, handles and control edges. Prevent trivial early traps caused only by invalid initial operands; *do not* prevent legitimate later traps or choose branches based on observed performance. The scaffold should enable multiple processes to exchange generic information without preassigning their social roles, functional goals, partners or repair responsibilities.

## Separating engineering calibration from emergence

1. **Calibration**: show the identical neutral opportunity grammar can create, expose, copy, revoke and transfer graph code, and log exact provenance. This is expected from the externally provided code and is NOT research evidence of emergence.
2. **Independent experimental arms**: add randomized novel CIL continuations after the neutral scaffold and compare them against identical neutral scaffolds with randomized continuation disabled, code shuffled and compute/storage matched.
3. **Prospectively fixed functional marker**: define a global information-processing function with a measurable output *without telling CIL which values are desirable*. Require it to be produced by multiple **internally modified** components not already completely constructed in the initial scaffold.
4. **Causal closure candidate**: preregister reciprocal component ablations and shams. Require two or more independent, separated observation windows where a lost joint function is restored by charged **internal** operations. External replenishment may provide environmental compute but cannot be counted as endogenous restoration.
5. **Independent holdout**: new seeds, distinct code-generation streams and replication counts must be frozen before results. Report all inert/trapped/no-op seeds, failures and confidence bounds; avoid selecting attractive trajectories from the first nine studies.

## Mechanism-specific acceptance rules

The study cannot claim life simply because the scaffold's expected code executes, because processes exchange information, or because externally arranged interdependence is disrupted. A positive CL-1 milestone requires **new functional organization arising after initialization, verified reciprocal internal dependency and internally initiated persistence/restoration** beyond what the scaffold guarantees.

Before experiment execution, publish a separate immutable `studies/10-preregistered-*.md` with the exact grammar, seed range, world capacity, expected positive-control exposure, intervention schedule, metric and disqualification rules. If the conditions remain unreachable, report **unexposed / not evaluable** rather than turning a zero into a life-property estimate.
