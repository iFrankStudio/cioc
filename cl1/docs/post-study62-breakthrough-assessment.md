# CL-1 research reassessment after Study62: the missing unit is a causally closed, composable organization

**Status:** critical research-direction memorandum, **not** a pre-registration, experimental outcome, life claim, or change to any frozen result. Source assessment date: 2026-11-14. CL-1 **OPEN**.

## Executive decision

**Highest-leverage research pivot: stop optimizing isolated graph operations and random-code length. Build a minimally composable, state-bearing, resource-constrained CIL ecology in which feedback loops are reachable *without pre-authoring a loop*, and then measure the first endogenous recurrent, information-dependent function and its causal maintenance.** Only after the first eligible function exists should a distinct preregistered lesion/recovery experiment be attempted. A positive causal closed loop would be an intermediate mechanism, **not** automatically digital life.

The current studies verify that native CIL self-editing, graph-object construction, limited child processes and code relocation work. They have not produced a sustained causal chain of sensing -> acting -> obtaining resources -> maintaining the sensing/acting organization. This is a substrate/compositionality problem, **not evidence that there are too few random trials**.

## Four code-level structural constraints currently confound biological inference

1. **No reliable feedback-bearing continuation.** `cl0/crates/lab/src/bin/cl1-study61-local.rs::seeded_world` freezes a 9-instruction *human-designed* scaffold plus 72 stochastic instructions. The random 24-choice continuation contains **no ordinary shared-cell `Read`**, though the scaffold has one. Its random `Write` is fixed `address:0, value:3`: output value is a graph-handle register, not arbitrary source-derived computed data. `Branch` tests register1, largely seeded by the scaffold. Source-derived output *addresses* can occur, but continued environment-sensitive input/output transformations are not a general opportunity. This is a **specific grammar defect**, not a theorem for the full CIL language.
2. **GraphLaunch is code migration, not organism inheritance.** `World::execute_graph` removes the graph object and moves its nodes into a new `Process::new(child_id, object.nodes, requested_credits)`; `Process::new` resets all registers to0 and starts PC0. Shared data, runtime registers, accessible handles and contextual working state are **not packaged in the child**. The parent does not copy its live executable/process state by GraphLaunch. New-process count is not reproduction.
3. **VM graph-local modulo closure is edge validity, not semantic preservation.** `GraphCopyNodeLocal` rewrites every edge to `(D+E-S) mod (D+1)`. For a source node0 `GraphNew(next1)` copied as new graph node0, the resulting edge becomes `0`, a valid **self-loop**, not preservation of the source's intended successor. Study62's recurrent one-opcode `GraphNew` copy into fresh graph objects reveals how code-edge validity may favor structurally sterile loops. This correlation does not by itself prove edge relocation caused the Study62 repeated actions. **Do not score locally closed edges or repeated instructions as successful code composition.**
4. **Energy and failure semantics block long causal histories.** Each native attempt costs one credit, and `World::step` schedules only unstopped actors with positive credits. Zero-credit actors cannot initiate `DrawCompute` even with a full shared pool; Study36 directly verifies this deadlock. Any `Trapped` instruction sets `stopped=true` permanently, so random invalid references can irreversibly kill the would-be constructor. Study38+ host generic one-credit ignitions extend activity but are **external actor activation**. Short, fixed 24-epoch cohorts with 12 attempted instructions/epoch and three unrelated preloaded random 82-node programs do not create a repeatedly varying, heritably selected population.

These mechanisms form an **opportunity bottleneck**: preloaded code is mutable in principle, but a closed, environmentally responsive, portable, resource-managing organization is barely reachable. Testing lesion recovery before a baseline function is evaluable would repeat Study14's `NOT EVALUABLE` mistake.

## Priority-ranked research directions

**P1 — Generic compositional data/code locality and observable functional feedback (highest near-term breakthrough plausibility).** Preserve existing Rust world kernel, deterministic CIL and SQLite traceability, but design **small, reusable native code/data graph fragments** with graph-local internal references and *explicit unresolved external ports*; failed external references are not silently forced to node0 by modulo. Ordinary native wiring must determine connections, not a host-coded viable circuit. Random fragments must actually have the generic opportunity to **Read updated shared information, branch on what was read, transform data, Write output, construct/alter graph objects and repeat**. Compare to the old frozen 9+72 grammar with source-pinned matched trials; keep the environmental response measure distinct from the grammar design. Avoid programmer-defined `Repair`/`Reproduce`/`Fitness` or an initial complete recurrent functional organism.

**P2 — Generic resource access without host actor-specific resurrection.** Evaluate an opt-in, universal world resource policy under which resource available to any process can pay the cost of *its own* next resource-acquisition action, with a fully conserved ledger and no code/fitness-based actor selection. A transfer must be a successfully executed **native CIL choice**, not host `SetCredits`. Include ambient input, no resource, resource accessible-but-unused, and original neutral-host-starter comparators. Distinguish environmental energy availability (legitimate) from environmental actor-credit rescue (not autonomous).

**P3 — Durable state and actual propagation/selection.** Prefer a persistent graph object that stores *code and ordinary state* with explicit ownership/capability information, so native re-creation can transfer meaningful information and connection history. Compare existing move-only `GraphLaunch` semantics (new child zero registers, old graph removed) to a generic explicit data-bearing handoff, conserving storage and credits. Do not automatically copy an organism identity or provide a reproductive template. Use competition for bounded compute/storage and trace **heritable functional dependence** over successive original-state changes or generations, not raw child count.

**P4 — Exposure-aware lesion/recovery, only after a non-scripted recurrent function is measurable.** Independently preregister selection of the **first** observer-defined native information-sensitive, repeated function per world, under fixed criteria and with all worlds in the denominator. Define functional equivalence by counterfactual input perturbation, not a hardcoded output. Then in matched branches apply real loss of the function-bearing graph/edge or state, sham, no resource, native-mutation-disabled and explicitly external repair controls. Record native code/data causality, process credit provenance, restoration of the **same functional map**, at least two later observation windows and no actor-specific host rescue throughout the recovery period. Exposed-world counts must be shown separately from all-world incidence; if baseline function never appears, recovery remains `NOT EVALUABLE`, not proof of life failure.

**Deprioritize:** more blind seed volume, random 72->144 node extensions, arbitrary branch weight/routing changes, optimizing W3 instruction counts, structural graph-closure scores, child process counts, ad hoc external refill or repeated tweaking of a single seed. Such changes already failed to bridge semantics, state inheritance or energy access.

## Suggested next experimental sequence (not a frozen protocol yet)

1. **Substrate feasibility matrix** (few explicit human-authored calibrations, *0 ecological worlds*): show a code/data graph can faithfully preserve *meaning*, not just edge bounds; an unassisted native read->state-dependent write->read cycle can remain causally active; native graph/state handoff retains intended values; trapped/invalid states and credit accounting are bounded. Negative fixtures include modulo-only dummy self-loops and external actor revival. This is calibration, not ALife emergence.
2. **Fresh independent opportunity ecology** (e.g. 128–256 new seed-worlds with strict new protocol): generic small fragments (not an engineered function), real repeatedly updated `Read`, generic computed `Write`, explicit wiring, resource-conserving scheduling. Primary = **at least one genuinely source-sensitive recurrent function spanning separate resource/observation windows**, with paired negative code-composition/feedback controls. Secondary = native reconstruction of the source-bearing executable graph. Report incidence per all seeds, per exposed seeds and true executed native provenance. Never select outcome-positive seeds.
3. **Separate prospective replication** with unchanged source grammar and new independent seeds, **then** native lesion/recovery and next-generation state/information retention. Scientific milestone is a **verified endogenous functional closure** before any claim of living autonomous organization.

### Scientific hypothesis to falsify

> The main limitation is lack of compositional closure and usable feedback/state/credit pathways, *not* a fundamental inability of CIL operations to encode self-maintenance. If unbiased local code/data fragments and energy-accessible feedback loops are supplied as **generic physics**, stable non-scripted information-dependent functions and causal maintenance will become measurable at higher prevalence than in the old random code grammar, even without a host-authored repair/fitness/reproduction routine.

A null under genuinely exposed, independently verified new worlds would falsify this *specific substrate-opportunity prediction* and warrant considering more fundamental digital chemistry representations, rather than seed mining.
