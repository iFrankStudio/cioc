# CL-1 Study101 — prospective HUMAN-authored branching native reproduction substrate

**PREREGISTERED MECHANISM ONLY; ZERO randomly generated ecological genomes.** After [verified Study100](../results/study100-verified-native-heritable-neutral-drift.md), the immediate bottleneck is not mutation existence but **lack of coexisting sibling descendants in the hand-coded single-child-then-halt lineage**. With no siblings, there can be no within-world lineage competition or differential proliferation of heritable variants. Study101 is a minimal capability check of ordinary CIL branching, NOT an adaptive/competitive ecological experiment.

## Frozen native strategy and initial world

Begin with the source-frozen Study99 complete16-instruction self-copier: native source Read(key7)→Write(key9), generic `GraphNew`, full-code `GraphCopyNode` of16 nodes in original position order, native pool Draw and `GraphLaunch`. Change only its last PC15 `Halt` to ordinary `Const {dst:1,value:0,next:4}`, allowing the same parent process (after launching a child) to return to its graph-copy preparation, create a new graph, copy all code again, draw compute and spawn a second child. The child inherits precisely the same executable loop. An existing CIL opcode is used, with no new VM clone/branch/reproduction law. The reproduction graph remains researcher-written and **does not contain random inherited mutations** in this study.

Human-scripted fixture: strictly bounded world `with_strict_capacity(4,64,1024)`, generic `pool_paid_draw` and `recoverable_draw_shortage`, one original parent id1 with **400** local credits, one external input cell7=3 or8, and one external shared compute pool **2400**. Draw and child GraphLaunch amounts both **240**. Deterministic scheduler and unmodified native one-attempt credit charging. Execute at most **1500** CIL attempted instructions per condition; interpret truncation explicitly, not as natural equilibrium.

## Three prespecified controls (both source values independently)

1. **Branching native copy + common pool2400:** require at least two distinct genuine child processes from original native parent1 and at least one actual native grandchild made by a native child, with full16-node original executable code and same-actor source Read7→Write9 in first three child/parent generations. Require successful generic native `DrawCompute(240)` for every process that launched a child, real `GraphNodeCopied` full16 per producing parent, and zero host-loaded descendants. Every `GraphLaunched` event must show internal origin, parent and child ids, moved_nodes=16 and transferred_credits=240. The shared compute pool may be exhausted; this is not eternal resource autonomy.
2. **No common pool:** otherwise same source code, externally pool0, require native `DrawDeferred` and **zero** children. Parent may continue attempting without progress and spend initial credits; no host-targeted refill or hidden rescue.
3. **Copy disabled via source-code comparator:** replace only original PC8 `GraphCopyNode` with a charged ordinary `Const {dst:1,value:0,next:9}` (no code copied). A later GraphLaunch of an empty graph must fail; require zero executable child processes and no false success. This comparator has **different original code** and is strictly a scripted negative control, not a statistical estimate.

All six combinations must conserve initial total compute inventory `parent400+pool2400` (or pool0) minus charged attempts, with native traps accounted, and only exactly three external events for initial parent load, source cell and pool setup. Any early trap, exhaustion, scheduler starvation or world storage cap must be reported and not called evidence of evolution.

## Frozen scientific interpretation

Success would demonstrate a **native finite branching genealogy** of function-preserving executable self-copying under shared bounded energy; it would not establish sibling competition, fitness selection, beneficial mutations, autonomous ecology, self-organization, or life. Different source values are matched conditions on the same human-authored genome, not independent ecological genotypes. **CL-1 remains OPEN.** A later separate prospective experiment must introduce actual inherited functional variations and measure their resource-limited differential reproduction without any host fitness/reproduction policy; that test must be preregistered before its data exist.
