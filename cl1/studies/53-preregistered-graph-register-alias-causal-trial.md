# CL-1 Study53 — preregistered causal native graph-copy register-alias experiment

**PROSPECTIVE registration.** Study49/51 produced strict native copy→edit→launch paths in 1/256 and3/256 separate original worlds, but none copied initial-program `Write`. Post-result Study52 found all four paths copied only early scaffolding `GraphCopyNode` (plus one `CloneNode`). In the original grammar, native `GraphCopyNode.source`, `.dst` and `GraphSetNext.node` all refer to register2, so the copied graph-local index overwrites the previously chosen random parent source index. This is a testable **generic CIL register alias** hypothesis, NOT life engineering.

## Frozen population and two paired language-topology regimes

- Exactly **128 fresh independent seeds 3,700,000..3,700,127**, all included. For every seed construct **two fully specified prefork initial worlds** with identical random-number choices but different *generic register topology*, each exposed to the same four environment conditions. The two prefork worlds are intentionally not identical to each other (the CIL graph-copy operands differ) but the four environmental arms **within each regime** must share byte-identical initial world snapshots.
- Both regimes exactly Study49 native world: strict cell32/process-node96/total storage512, three-actor 9-op prefork scaffold, 27 original charged prefork attempts, 47 credits per original process and 48 externally endowed pool, 72 continuation nodes indexes9..80, Halt81. Exactly the original 24-way choice and wrapping LCG, including the independent choice8 source-register2 value `random(state)%81`. No opcode count or choice weight changes, no manual graph assembly sequence, no survival/repair/reproduce code.
- **`alias` (negative baseline):** *byte-for-byte* original Study49 random continuation, including `GraphCopyNode{graph:3,source:2,dst:2,next}` for choices1 and20 and `GraphSetNext{graph:3,node:2,target:0,next}` for choices16,21,22.
- **`separate` (generic register topology treatment):** for *every* native random continuation `GraphCopyNode` in choices1/20 use `dst:0` rather than2; for every `GraphSetNext` in choices16/21/22 use `node:0` rather than2; all other fields and choice8 randomness stay identical. This gives the copied local-node index a distinct result register while keeping the randomly chosen original parent source register2 stable through GraphCopyNode. Register0 may be used by native Write/Add; these are part of the treatment's actual collateral effects, not adjusted after the fact. No other opportunistic repairs or tailored instructions.
- Same four matched environment arms in each regime, fixed order: `ambient-general`, `ambient-only`, `closed-general`, `zero-credit-ambient-general`. Identical native quota12 ×24 epochs, external +8 world-pool credits on epochs1..23 where enabled, neutral one-credit activation of the lowest-ID unstopped zero-credit actor only if no runnable actor, no inspection of goal, code or fitness. Every transfer is exactly one existing world-pool credit and recorded `External`; runtime and CIL semantics unchanged.

Total **256 native prefork programs across 128 independently selected seed pairs**, **1,024 matched runs** (128 seeds × two topology regimes × four conditions), **24,576 original SHA256 snapshots**.

## Interpretation

This is a **neutral program-composition and operand-alias test**, not a programmed organism. The environment still supplies ambient compute and optional one-credit process ignition. A successful Write copied into a child graph is not native execution, and a native child CellWritten is not adaptive reproduction or endogenous recovery. **CL-1 remains OPEN** until independently confirmed multi-component causal closure, native damage repair and unassisted cross-window functional maintenance.
