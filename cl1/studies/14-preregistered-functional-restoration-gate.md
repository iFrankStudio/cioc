# CL-1 Study 14 — preregistered functional-restoration feasibility gate

**Registration:** 2026-11-13. This protocol is frozen **before** a Study-14 runner, any Study-14 outcomes, or outcome-based selection. Studies 01–13, including the 4/96 early reciprocal patterns and 0/96 late patterns in Study 13, are known. **Status: PREREGISTERED / NOT EXECUTED.** This document registers an experiment, **not** a successful life result.

## Question and falsifiable hypothesis

The previous bidirectional-copy indicator was too rare and short-lived to measure maintenance. Study 14 first asks whether the existing general-purpose CIL and observer can *measure* recovery of a specified information-transformation function after a targeted loss, and discriminate internally executed reconstruction from an investigator's direct restoration. This is a **calibration** study: success of an externally scripted positive control does not establish emergent self-maintenance.

The independent observable is an epoch-level **functional result**, not a count of graph copies, occupied nodes, running processes, or successful permissions. If the planned positive control cannot restore the function under the same budget, the functional maintenance endpoint is **NOT EVALUABLE**; it must not be recorded as an endogenous zero.

## Non-teleological substrate

Use the existing CL-0 deterministic Rust world, CIL instruction set, explicit external epoch clock, strict compute/storage accounting, source-attributed events, SQLite replay and independent Python inspection. No host `Repair`, `Fitness`, `Reproduce`, automatic restart, hidden score, autonomous seed selection or new privileges.

Any calibration code that deterministically exercises reconstruction is authored by the researcher, tagged **externally initialized** even when its instructions execute as `Origin::Internal`. Distinguish **instruction execution provenance** from **information design ancestry**. No experimenter-supplied template may be reported as discovered algorithmic novelty.

## Two independent, separately labeled arms

**A. Mechanism positive-control calibration (hand-authored):** build a fixed process/object fixture *before any random ecology*. It must demonstrate that (i) a fresh graph is allocated with charged CIL instructions; (ii) a node copied/edited from an already-existing permitted code source obtains a traceable lineage; (iii) an externally imposed damage eliminates a predefined input/output transformation; and (iv) an **explicit investigator-directed** restoration, if supported by the native generic instruction vocabulary, restores that transformation. If the current host intervention API cannot restore the *same* damaged object, declare the external-restoration control **UNIMPLEMENTED** and **DO NOT** substitute a different operation or call a new object an exact restoration. Report failed mechanism tests. This arm is not a statistical estimate and can never support stage acceptance.

**B. Random continuation prospect (no repair template):** 96 new, distinct seed-worlds numbered **2,140,000..2,140,095**; reuse Study-13's publicly documented 3-process neutral nine-instruction opportunity prefix, 18 randomized instructions/process, LCG and budgets **without modifying instruction weights after seeing outcomes**. Prefork: 27 attempted CIL instructions, then fork from identical serialized world state. A fixed **24 externally clocked epochs × 12 opportunities** follows in each branch. This is a new distribution-specific feasibility probe, not an independent sample of all possible programs or digital worlds.

## Registered matched randomized-ecology conditions

Six paired branches **per seed** from the same prefork snapshot:

1. `control`: no intervention.
2. `sham`: rejected `DropGraph { graph: 0 }` at epoch 0.
3. `drop-g1`: externally drop graph 1 at epoch 0.
4. `drop-g2`: externally drop graph 2 at epoch 0.
5. `drop-both`: externally drop graphs 1 and 2 at epoch 0, fixed order.
6. `zero-credit`: externally set each extant process's credits to 0 at epoch 0.

**Denominators:** exactly 96 independent seed-worlds, **576 paired runs**, **13,824 postepoch snapshots**. Preserve all trapped, halted, inert, externally aborted and functionally unexposed worlds. No seed dropping or post-hoc tailoring. A failed scheduled ablation or unequal prefork hash invalidates the affected cohort's technical acceptance, not silently the scientific denominator.

The direct-external-restoration positive control belongs **only** to mechanism arm A until a comparable, safe intervention is implemented and preregistered for random arm B. Never compare a structurally different restoration (e.g. `PatchEdge` on a process) to `DropGraph` on an object as if identical.

## Functional observables and observation windows

For arm B, a successful information transformation requires an explicit internal `GraphCopied` event with source/target owner distinct, **plus** evidence in the same epoch that the recipient subsequently uses the copied information in a **predeclared output cell update**. Current event provenance records copies but **does not uniquely attribute causal cell writes to source nodes**; until this is independently auditable, classify the transformation marker **NOT EVALUABLE** and report graph-copy *exposure* separately. A graph-copy alone must not count as useful transformation.

Define fixed windows **W1 = epochs 0..7, W2 = 8..15, W3 = 16..23**. Registered descriptive endpoints: successful postfork cross-owner graph copies; postfork internally executed `GraphCreated` followed by charged `GraphNodeCopied` or `GraphCopied` on the same graph; witnessed post-damage object creation; complete information-lineage chain (if implementable); and any new nonempty graph object after lesion. All must use pre-action ownership and identify the first actor and event origin.

The primary functional recovery outcome requires all of: functional output present in control **W1**; targeted ablation removes that **same input/output relationship** during W1; no experimenter repair in the treatment; a traceable, internally assembled replacement relationship present in **both W2 and W3**; and a non-null sham equivalence test. Until source-sensitive output attribution is implemented and the mechanism control passes, this **primary outcome is NOT EVALUABLE**, not zero.

## Integrity and controls

- Control/sham final world contents must match, except the external event and clock metadata. Any divergence is a **study-wide technical failure**.
- Zero-credit arm must execute precisely **zero** postfork internal attempts.
- Every delivered intervention must be observable with `Origin::External`; none can count toward endogenous recovery.
- Exact SQLite replay of **576/576** branches, **13,824/13,824** postepoch world hashes, identical prefork hashes per matched sextet, occupancy <=192, and no compute inventory overflow.
- Every endpoint is computed by independent read-only analysis. Freeze code/version and report hash and negative denominators.
- Interval summaries use the **96 seeds**, not 576 correlated branches. Describe Wilson 95% intervals as conditional on this deterministic generator family, not a universal life frequency.

## Interpretive decision rule

- **Mechanism control fails / source-sensitive functional marker uninstrumented:** functional restoration is **NOT EVALUABLE**. Report reachability counts but never treat a null functional measurement as a negative estimate.
- **Functional marker evaluable but no control W1 exposure:** organizational maintenance **UNEXPOSED** for this seeded ecology.
- **Control exposed, no recovery:** bounded negative result for this grammar/horizon.
- **Recovery candidate exists:** reproduce with source-pinned full replay; subsequently preregister independent holdout seeds, budget-matched scrambled-code controls, direct external restoration and component-specific double ablations **before** any positive organizational-closure claim.

**CL-1 stage acceptance remains OPEN.** A scripted mechanism fixture is never life, and output persistence alone is not organizational closure. This protocol cannot retroactively change Study-13 results.
