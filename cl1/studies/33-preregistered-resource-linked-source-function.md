# CL-1 Study 33 — preregistered joint source-dependent function and native compute uptake

**Frozen 2026-11-14 before any Study33 implementation, seed execution or results.** Studies27/31 already established an externally code-tag-sensitive output-address register chain in **2/192** worlds, while Study32 observed finite native compute uptake and execution-budget extension in **86/192** different worlds. The missing scientific question is whether these abilities ever coexist in the **same native actor and same functional trajectory**, and whether initial pool availability makes a paired difference. Neither separate result is evidence of an organism.

## Sampling, generator and resource environment

New independent seed-world IDs **2,600,000..2,600,127**, exactly **128 new worlds** disjoint from all past cohorts, with no seed filtering. The CIL random generator is **byte-for-byte identical to Study32**, save the seed range and recorded source revision: externally authored three-process nine-instruction scaffold, 27 native charged common-prefork attempts, GraphNew and single-code-node owner graph1–3 with reader ACL, three shared prefork cells, 18 randomly drawn ordinary continuation instructions per process with the *same 64-bit LCG and `random()%12` opcode mapping* (`GraphCopyFrom, GraphCopyNode, DrawCompute, GraphReadTag(g1), GraphReadTag(g2), Add, Write×2, Const, Branch, ReturnCompute, GraphGrantRead`). Strict storage cells32/maxnodes40/total192, 56 initial compute credits/process and **47 remaining credits/process after prefork**. The researcher externally endows the environmental pool with **48 units** before common prefork; this is neither internally produced energy nor an evolutionary incentive.

Exactly **9 paired arms**, **1,152 matching runs** and **27,648 hashed SQLite postepoch snapshots** (24 epochs ×12 native attempts per branch, W1 epochs0–7, W2=8–15, W3=16–23):

1. `control`: original graph2 tag11, pool48.
2. `mutate-g2`: externally `DropGraph(2)` then `PutGraph(2)` with ONLY original graph2 node0 replaced by Halt, producing tag19; owner2/readers/graph ID unchanged, pool48.
3. `empty-pool`: same graph2 tag11, external `SetComputePool(0)` at epoch0.
4. `mutate-g2-empty-pool`: graph2 code edit followed by pool emptying at epoch0 (fixed intervention order).
5. `refill`: graph2 original and pool48, externally `SetCredits(process,47)` in ID order at epochs8 and16.
6. `mutate-g2-refill`: same original graph2 code edit at epoch0 and external credits at epochs8 and16.
7. `sham`: rejected external `DropGraph(0)`, exact simulated-state match with control.
8. `exact-original-g2`: external drop then reinject same graph2 object, exact simulated-state match with control.
9. `zero-credit`: external `SetCredits(process,0)` in ID order at epoch0; zero native instructions.

Matched graph2 edit is always experimental *external*, never classifiable as endogenous code rewriting. An initially empty pool can be refilled **only through native ReturnCompute**; therefore successful Draw in that branch is recycling, not energy creation. Controls do not restart halted/trapped programs.

## Frozen native provenance and causal endpoints

Use only source-specific native successful events with `Origin::Internal(1)` and exact PC in the actual original process1 `code.nodes`. The native `GraphTagRead {graph:2, owner:2,node:0,tag}` labels the register written by its actual `GraphReadTag.dst`. A conservative register def-use interpreter tracks labels across all other register writes, `Add/Sub` propagating label unions, and requires an actual successful `CellWritten` at `Op::Write.address` from a still source2-tag-labelled register; any unsupported or ambiguous opcode must **fail closed**. The event's actual `CellWritten.key` must match 11 or 19 respectively.

**Primary A — joint successful native source-and-compute operation:** per seed, in the `control` arm, at least one successful process1 `DrawCompute` from the pool *before* a native process1 source2-tag-def-use-qualified successful `CellWritten(key=11)` in the **same epoch**, with no intervening external process-credit refill in that epoch. Count seed-worlds/128 with positive causal register provenance, and separately the broader successes with just prior native Draw. A native Draw by process2 or 3 or later than Write cannot qualify.

**Primary B — paired externally induced source-content-sensitive address + compute:** same seed must have a qualifying process1 source2-tag write to cell11 in `control` and corresponding tag19 write to cell19 in `mutate-g2`, with **equal written value**, each preceded in the same epoch by a successfully charged native process1 DrawCompute and native source2-tag read. Use equal actor and **same epoch** in both branches, not just adjacent unrelated events. Report strictly paired seed-world count, separate exposure denominator and individual branch successes. The source edit establishes value-address sensitivity under external intervention; it does not prove functional self-maintenance.

**Primary C — actual extension of source-sensitive function by native uptake:** subset of Primary B where at least one qualifying source-tag-labelled `Write` in each arm occurs after that actor has executed **more than its original 47 postfork charged native instruction attempts**, with positive native `DrawCompute` by that actor before its write, **and no postfork external SetCredits to that process**. Compare matched `empty-pool` and `mutate-g2-empty-pool` opportunities; report dropouts, retained outputs after native recycling, and no-evaluable exposures separately. Do not infer that a missing output in an emptied-pool arm was causally caused by pool availability without a separately matched source-read and instruction-execution witness.

Precommitted secondary metrics for **all three windows**: worlds with native process1 successful graph2 reads, register-lineage-qualified target writes, successful native process1 Draw/Return, >47 native process1 attempts, paired source-edit output discordances, native charged activity, W3 successful outputs, and source-output opportunities under external refill vs no refill. All outcomes require independent world denominator 128 and Wilson 95% intervals; paired arms are not independent samples. Zero qualified worlds is recorded as a strict-null **exposure finding**, not a mathematical impossibility.

## Technical scientific acceptance gates

- Before outcome interpretation, Rust must execute and **exactly replay each of the 1,152 matched 24-epoch SQLite sequences**. Independent read-only Python must verify **all 27,648** snapshot hashes, exact source revision, seed range, identical prefork hashes, precommitted program grammar, external intervention order, source graph2 node0 real content/owner/read permission, strict storage and compute inventory, and rejected-sham/unaltered reinjection simulated-state equivalence.
- Native resource pool ledger must independently reconstruct all successful `DrawCompute`/`ReturnCompute` by actor/PC and exact **register1 quantity 2,3,1**, reconcile every snapshot `compute_pool`, reject success without compute or process credits and never count trapped native instructions as successful.
- Synthetic positive control must verify a native source2-tag-labelled read routed through ordinary `Add` to a successful Write and the same-actor successful Draw preceding it. Negative tests: register overwrite, wrong owner, wrong actor, Draw after Write, prior Draw by another actor, output before source read, wrong source tag, duplicate output and failed native Draw.
- Maintain full original unselected cohort and raw negative cases, no reweighting, filtering, hindsight sequence tuning, REPAIR/FITNESS/REPRODUCE opcode or host-level reward. Do **not** lower Stage CL-1 acceptance based on overlap of source-dependent I/O and native compute uptake: even complete Primary C is only an early combined opportunity from **researcher-authored code and finite externally endowed resources**, not persistent self-repair or an internally formed two-component organism. **CL-1 remains OPEN pending functional damage-and-internal-restoration across two later windows and independent replication.**
