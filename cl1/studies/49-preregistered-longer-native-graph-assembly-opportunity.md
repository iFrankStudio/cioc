# CL-1 Study49 — preregistered independent longer stochastic graph-assembly opportunity

**Frozen prospectively before implementing, sampling, or running this cohort.** Study44 and Study46 each produced **0/128** native-launched child shared-cell writes. Retrospective Study48 traced all 256 historical seed-worlds and found **0** native same-parent, same-graph `GraphCopyNode(nonzero)` followed by `GraphSetNext` before `GraphLaunch`; successful isolated copy/edit/launch events were not connected as the full construction sequence. Study47 deliberately **scripted** such a sequence and demonstrated a successful child Write with a graph-local edge; that is a mechanism calibration, not endogenous emergence. Study49 is a **new stochastic opportunity test**, not a repair/reproduce/fitness program.

## Fixed population and native world

- Exactly **256 new independent seeds**, sequential **3,500,000..3,500,255**, with **no filtering** and **no pilot inspection**. The frozen Rust runtime and CIL opcode semantics are unchanged.
- Same 3-actor Study46 nine-op scaffold and 27 prefork charged native attempts; 56 starting credits/process, **47 remaining credits/process** at fork, **48 researcher-endowed world-pool credits**, strict cell limit32 and process executable node capacity **96**, strict shared storage total **512** (extra room necessary for longer initial programs). Up to24 epochs ×12 native charged attempts/epoch.
- Exactly Study46's 64-bit wrapping LCG state transition and its exact **24-way random continuation opcode table**, including one additional LCG step exclusively when random choice8 generates a uniform source index. **Only opportunity modifications from Study46:** append **72 random continuation nodes** at indexes9..80 inclusive (instead of 36 indexes9..44); `Halt` at index81 (instead of45); random choice8 `Const(dst=2,value=random(state)%81,next)`, drawing uniformly from all **81 pre-Halt nodes**. The 24-way selection weights, register operands, code targets, and ordinary linear edge to next node are otherwise byte-for-byte those in Study46. No deliberate graph-local closure program or favorable sequence, no seed-selected repair.
- The long program may trap, consume its credits, or fail to reach the second half. Such failures are essential science and stay in the denominator.

## Registered four matched conditions per seed

The exact prior Study46 environment conditions, order and policies:
1. `ambient-general`: external ambient +8 world-pool credits per epoch1..23 and neutral generic one-credit pool→process startup iff no runnable actor, earliest actor ID (no code/fitness inspection).
2. `ambient-only`: same ambient pool input but **no host one-credit starter**.
3. `closed-general`: no new ambient energy, same neutral generic starter policy.
4. `zero-credit-ambient-general`: at epoch0 external SetCredits=0 for each original actor, then ambient+generic starter.

All four branch from **byte-identical prefork world per seed**, full original 24 hashed snapshots, original event ledger and exact replay through `Laboratory::run_epochs`. Every environment action is externally attributed; all native instructions still cost one credit. No hand-authored organism, repair policy, reward, preselected good source node or host code repair.

Total **1,024 matched runs and 24,576 hashed snapshots**.

## Frozen primary endpoint

Count among all **256 `ambient-general` seed worlds** the fraction containing at least one **successful native-launched child `CellWritten`** attributable to a previously recorded, same-source-history `GraphLaunched` event, native child process/PC and executable `Write` opcode, and actual cell key/value. A child must originate from internally executed CIL `GraphLaunch`, not `Intervention::PutGraph` or researcher-created process. Report denominator256, exact count, Wilson95 interval, and first deterministic witness if any. **Zero is a valid negative result.** A positive demonstrates a finite stochastic graph-building phenomenon, **not autonomous life**.

## Frozen mechanistic secondary endpoints

- Successful native launched children, successful non-GraphNew child opcode executions, child native shared writes, exact completed program edge closure and executable length at launch (never confuse final code modifications).
- Direct source graph assembly pathway: successful **same-parent same-graph** native `GraphNodeCopied` of a source node other than original node0, then native successful `GraphNodeEdited` of the graph, then same-parent successful `GraphLaunched`, in strictly ascending tick order; report world-level prevalence and event counts for each gate. This is distinct from the primary and neither necessary nor sufficient for true function/heredity.
- Successful original-actor self-code mutations, subsequent original-actor native cell output, W1/W2/W3 native charged activity, and native child activity in two distinct W3 epochs with no same-epoch host starter. Report fixed matched four-arm contrasts and resource origin explicitly.
- Negative controls: absence of external child injection, all 256 frozen seeds, exact initial program generated from independent Python LCG including extra RNG draw at choice8 and `%81`, actor code length82 and initial prefork credits47, full matching bytes of initial worlds across arms, original event source attribution, every epoch hash and external schedule, total compute conservation and native graph-write actor/parent lineage.
- Exactly **two** focused synthetic calibrations: valid successful native child Write following earlier GraphLaunched, and fraudulent child Write with no native launch must be rejected. Do not inflate incidental tests.

## Interpretation and next decision

A positive does **not** imply endogenous repair, beneficial mutation, parent→child causal interdependence, inheritable phenotype, sustainable energy acquisition, or digital life. A failure can distinguish sparse native graph-assembly paths from a VM opcode deficiency (Study47 was positive). Next work must analyze source-specific child code portability and eventually genuine endogenous functional restoration after a lesion in separately preregistered independent worlds, not post-hoc revise this primary.

**CL-1 remains OPEN.**
