**Status:** separately preregistered BEFORE implementation/selection/execution of any Study42 seed. Study41's result is already known: 64/128 unique actor-native executable code changes, 52/128 native child-launch worlds, 12/128 children subsequently executing, under frozen stochastic CIL opportunity, *not* life or repair.

At most one externally sourced starter per epoch; it transfers one existing pool credit to the lowest-id unstopped zero-credit process if and only if no runnable process exists, **without examining opcodes/fitness/output**. All process IDs up to exact storage capacity 256 included.

## Frozen primary scientific mechanism

Number of independent `ambient-general` worlds with at least one **uniquely attributable successful native original-actor PatchNext/PatchConst/CloneNode executable code change within an epoch**, requiring actual executable before/after code difference, exact internally sourced event PC/tick and **one** unambiguous successful mutator of that actor in the epoch. The confidence interval is Wilson 95%; no seed exclusions, no success threshold adjustment after outcomes. A directional independent replication is any **>0/128** verified positive worlds under the same original grammar and auditor, but scientific interpretation must include both exact effect estimate and uncertainty.

## Frozen secondary gates and negative controls

- Initial/final code inequality per original actor, successful native mutator events (separate from trapped attempts), successful GraphLaunched event with new child ID, at least one successful child native attempt, child successful instructions across at least two distinct epochs, successful native shared-cell Write after native code change, subsequent native original-actor execution after self-code mutation.
- Preserve four-arm treatment contrasts and explicitly distinguish early native plasticity from late host neutral ignition, ambient external energy, and direct process refill (none in this study).
- Independent Python auditor reconstructs exact seed/code grammar and check all 12,288 per-epoch SHA256, external action order/amount, code-change-only-native witness, source attribution, no phantom child, strict compute accounting, and full 128×4 matched population. A native GraphCopyNode changing *graph data* is never an original actor executable-code modification.
- Native code editing or process launch is **not** goal-directed self-repair, evolutionary adaptation, organism identity, heredity or life. No new code opcodes, no preloaded repair/rank, no targeted host lesions/rescues, no successful-seed pilot.

## Interpretation and next decision

A replicated native mutator capability justifies **separate prospective causal functional-maintenance tests** under real lesions, source ablations and no-host-rescue controls. It does not demonstrate that any code change is beneficial or that launched children maintain parent function. CL-1 remains **OPEN**.
