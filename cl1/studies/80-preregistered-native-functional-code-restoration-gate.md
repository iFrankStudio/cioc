# CL-1 Study80 — prospective native code-function lesion and internal restoration gate

**Status: PREREGISTRATION ONLY. NO Study80 worlds have been run, no code-restoration result is claimed.** This protocol is frozen after verified Studies77–79. The new scientific question is whether a **native-executed** source-sensitive computation can regain its original function **because of internally executed CIL code edits**, rather than merely because a researcher supplied nonfatal Draw physics, public compute or a replacement program.

## Rationale and non-negotiable provenance

Studies77–79 established finite W2/W3 native Read(key7) -> Write(key9) coupled to actual DrawCompute, and established the precise fatal-vs-deferred resource-shortage contrast. They did **not** demonstrate CIL editing its own effective executable graph, damaged-program recovery, stable multi-part closure, inheritance, or life. Study80 shall not silently reinterpret DrawDeferred as endogenous repair. Both environmental laws and source input ports remain external boundary conditions.

## Phase 0: mandatory mechanism-feasibility calibration (ZERO stochastic ecological genomes)

Before any new ecological seeds, show with externally hand-authored fixtures that the **existing** CIL graph-editing instruction(s) can (a) write an instruction/edge whose original source is not copied verbatim from a researcher-injected repair, (b) actually change the later source-dependent CellWritten output, (c) survive a precisely located external deletion/replacement of a function-critical instruction/edge and (d) recover that same source-dependent function through a **later native edit**. Keep explicit host-repaired positive and mutation-disabled negative fixtures. If any fixture is impossible using the current grammar or existing permissions, report **NOT EVALUABLE** and stop: do not add a special repair opcode, change seed grammar after observing ecological outcomes, or count scripted fixture recovery as emergence. A generic new primitive, if scientifically necessary, must have its own separate mechanism study and independently frozen prospective ecology.

## Phase 1: fresh prospective ecology, only after successful Phase 0

Use exactly **128 new initial code genomes** with nonoverlapping integer seed labels **5,300,000–5,300,127** and deterministic SplitMix64 mixing, a source-committed grammar, fixed code length, fixed resource law and scheduler, and one untouched initial-genome hash per seed. Do not reuse Study77/78 genomes, cherry-pick by promising phenotype or exclude no-exposure seeds. Build every matched arm from the **same byte-identical initial genome**; hash all full initial code/graph state before mutation. The environmental source-port low/high values are 3/8, and target numeric output difference is +5 where a source-dependent function is observed. External ambient supply and opt-in recoverable Draw semantics may be used as *identical disclosed physics in all primary arms*, not varied to maximize recovery. Any deviations from Study77's 24 epochs/12 attempts per epoch or 64 initial local credits must be frozen **before** new-run outcomes, with scientific justification. Source of any future functional code must be traced to actual actor, instruction, operand register ancestry and graph ownership.

### Matched arms (per original genome and source-input variant)

1. **Intact:** no lesion, standard native graph edits enabled.
2. **Sham:** same scheduled host intervention and credit accounting but no code change.
3. **Lesion + native edit enabled:** targeted externally introduced damage to one *function-critical* instruction or edge, with no repair help.
4. **Lesion + native edit disabled:** identical damage, suppress only native executable code-changing operations, preserve cost and unrelated VM semantics.
5. **Lesion + explicitly external exact restoration:** same damage, host restores exact pre-lesion bytes at a declared fixed post-lesion epoch, logged as External; verifies restoration assay sensitivity, never counts as endogenous repair.
6. **Lesion + native resource uptake ablated:** identical damage and edit rights, but successful DrawCompute disallowed using documented matched resource semantics; isolates dependency on native energy access.

Run source low/high for every condition. If no function-bearing target exists at the predeclared pretreatment checkpoint, the scheduled lesion is recorded as **not exposed** and **the world remains in the 128 denominator**. The target choice must be deterministic and inspect only **pre-lesion** execution lineage: the lowest (graph-id,node-id,edge-index) concrete code site that is indispensably on an actually executed source-sensitive Read-to-Write path. Do not use future recovery information to choose an intervention. Host lesion, sham, and external restoration events must carry external provenance.

## Frozen outcome hierarchy

**Prerequisite exposure E:** successful native, PC-attributed Read(key7) and same-actor source-dependent CellWritten(key9) at the same writer PC under low/high input before intervention; a concrete eligible function-bearing target must exist at the fixed pretreatment time. Report E/128, including whether paired low/high qualification and exact +5 value hold. Missing E is **NOT EVALUABLE**, never a successful or failed *exposed* repair.

**Functional loss L:** after external lesion, the baseline expected source-sensitive output is absent or changed under both matched source variants in the first prespecified post-lesion observation window, while matched sham retains the original function. Report L/E, and all-world L/128 separately. A lesion that fails to interrupt function is **not an effective lesion**, not a recovery.

**Native restoration R (primary):** among exposed effective lesions, function reappears in **two nonoverlapping later windows**, meeting the original same-actor, same-writer-PC source low/high +5 test; a real post-lesion native executable-graph edit is independently verified to have altered the damaged functional path *before* recovered writes; native mutation-disabled arm stays functionally lost in the corresponding windows; no external code restoration, process-targeted credit recharge, privileged repair operation, unobserved graph source or mistaken static/dynamic operand attribution. The exact old byte sequence need not return if causal function does, but effective changed graph/code and its internal ancestry must be proven. Report R/E, R/L and R/128, never convert unevaluable seeds into positive outcomes.

**Energy dependence (secondary):** report R with/without actual successful native DrawCompute preceding restored output, at >64 total native charged attempts, plus results with Draw ablated; mere DrawDeferred or pool availability is not sufficient.

**Higher-order closure gate (not inferred from R):** any CL-1 acceptance needs **at least two distinct causally essential internally maintained components**, reciprocal damage sensitivity, time-separated effective restoration and perturbation-negative controls. A one-component native code repair, even if observed, is a new intermediate milestone and **not** cyberlife or organizational closure.

Freeze exact intervention epoch, output windows, deterministic target selection algorithm, native-mutation ablation semantics, generator source SHA, exact scripts/queries and statistical tests before executing any new genome; if eligible targets or native-edit access cannot be defined without post-outcome tuning, mark design blocked rather than backfill. Independently verify Rust deterministic replays, native attempted-instruction and resource conservation, all SQLite epoch SHA256 records, source-to-register def-use, effective code and PC ancestry, and explicit External vs Internal events. Count trap, no-exposure, no-write, sham failure and nonqualifying outcomes. Report paired discordant counts and exact paired tests for the mutation-enabled versus disabled exposed matched worlds; statistical summaries over fixed seeded CIL worlds are **not** estimates of the prevalence of life in arbitrary digital environments.
