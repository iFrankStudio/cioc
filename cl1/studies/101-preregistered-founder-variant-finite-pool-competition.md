**STRICT PROSPECTIVE HUMAN-CODED MECHANISM STUDY; ZERO independently sampled ecological genotypes.** Registered after verified native whole-code inheritance Study99 and native neutral mutation Study100. Research question: can source-function-bearing native self-replicating code lineages with differing *instruction costs* compete for the exact same finite public compute pool, with differences emerging only from VM execution and scheduling rather than a host fitness/reproduction oracle?

- **S (slow):** PC4 `Const R2=1 ->16`; the 42-step neutral delay is executed every generation, then rejoins atPC5.

Only PC4's `next` differs. Both must perform the same native source-dependent function and the same20-node self-copy and Draw/Launch. Neither variant is produced by a naturally sampled stochastic mutation; the host deliberately loads them at epoch0. All subsequent descendants must inherit the genuine variant without host intervention. Differences in children per fixed attempt horizon are an **engineered pre-existing standing-variation competition**, NOT proof of emergent adaptation.
