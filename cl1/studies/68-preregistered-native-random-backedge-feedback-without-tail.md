# CL-1 Study68 — prospectively registered random native backedge compositional feedback without a researcher-prewired cyclic tail

**STRICT PROSPECTIVE REGISTRATION.** Stage64 and independently replicated Stage65 demonstrated W2+W3 true native source-tainted feedback in 5/128 and 9/256 random CIL genomes **only when the researcher supplied a cyclic tail**. The matched Study65 `linear` endpoint with a tail `Halt` was 0/256. Stage66 independently revealed that adding rare native DrawCompute under a tiny initial credit supply does not sustain functional feedback (0/256) and leads to zero-credit deadlock or fatal resource trap. Study67 post-result classification distinguishes the two causes. Stage68 isolates whether random-program **control-flow topology alone**, *without* a guaranteed cyclic tail, permits repeated, information-dependent native Read→Write. It is NOT a self-assembled organism or a life-repair experiment.

## Frozen independent population and common CIL grammar

- Exactly **256 NEW independent genome seeds4,500,000..4,500,255**, no pilot selection, early stopping or reused source worlds. Each genome produces eight correlated matched conditions: two branch control-flow topologies `short` vs `broad`, two independently provided source sensor inputs3 vs8, plus matched Read-ablation. **2,048 source-pinned native runs**,24 epochs×12 charged native attempts, **49,152 independent SHA256 epoch snapshots**.
- One original actor process1, researcher endowed with **300 finite initial credits**, pool0, strict storage caps4 shared cells/32 executable nodes/64 total. **No** runtime host interventions, `SetCredits`, environmental resource injection, DrawCompute, graph construction, reproduction, mutation, damage or targeted repair. W3 execution with this finite endowment is not resource autonomy.
- Exactly Stage65 three researcher-provided generic register interface instructions PC0..2: `Const(r1=1)`,`Const(r2=7)`,`Const(r3=9)`. Exactly 24 randomized CIL nodes PC3..26 using the same 64-bit wrapping LCG `state=state×6364136223846793005+1442695040888963407` and six uniform choices `random(state)%6`: 0 Read(r0,address:r2) (or ablated Const(r0=0)); 1 Write(address:r3,value:r0); 2 Add(r0,r0,r1); 3 Sub(r0,r0,r1); 4 Const(r0,random(state)%8); 5 Branch(test:r0,zero:PC+1,nonzero:...).
- On **every random Branch choice5**, both topologies consume **one additional identical LCG draw** `edge_choice=random(state)`, including a draw for PC3. `short` Branch.nonzero = PC3 if PC3, else PC−1; `broad` Branch.nonzero = `3 + edge_choice % (PC−3)` for PC>3 (uniformly a strictly earlier node PC3..PC−1), else3. All other opcode identities, Const values, operand registers, linear successors and random draw chronology remain paired and identical. This is a **generic random edge distribution change**, not a hand-coded successful Read→Write loop.
- **BOTH topologies terminate in `Halt` at PC27.** No researcher-prewired tail `Branch` or other guaranteed return to PC3. All observed recurrent feedback must come from random Branch instructions already included as native executable data, not from a supplied cyclic connector. This experiment tests *genotype-level random control flow*, not native-lifetime `PatchNext` self-assembly.

## Interpretation and stop rule

A positive establishes **randomly encoded generic control-flow affordances can support source-responsive operation composition without researcher-supplied cyclic tail**, subject to confirmation on an independent fresh-seed cohort. It does **NOT** demonstrate self-built executable graph, durable data-bearing handoff, native compute acquisition, repair, genotype inheritance, multicomponent organization or life; the initial 300 credits, interface and branch grammar remain researcher provided. A zero is a useful falsification of this specific small random branch topology opportunity and must not trigger after-the-fact changing LCG, seed count, feedback criterion or data.
