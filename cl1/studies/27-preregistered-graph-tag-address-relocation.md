# CL-1 Study 27 — preregistered independent confirmation of graph-tag-dependent output address

**Registered 2026-11-13 before Study-27 code, seeds, exposure or results.** Studies 25–26 are known: three post-hoc exploratory source-graph2 tag mutations changed a native read from 11 to 19, coinciding with loss of cell11 output and other-cell writes. The **specific hypothesis that address 19 replaces address 11 is new and untested**; it is registered prospectively here, not retroactively attributed to Study 25.

## Hypothesis and necessary causal contrast

In newly sampled random CIL worlds using the unchanged Study-25 3-process/27-attempt prefork generator, successful **graph2 code tag** reads (tag11 in intact graph, tag19 in experimentally edited graph) may be used by process1 as a **write address**, relocating the same-actor successful output from shared cell11 to cell19.

**Primary registered criterion per independent seed:** under paired *identical prefork* `control` and `mutate-g2` worlds, both in **epoch0**, process1 successfully records `GraphTagRead { graph:2, owner:2, node:0, tag:11 }` in control and tag19 in mutation; **after** those reads and in the **same epoch**, control process1 successfully `CellWritten { key:11, value:v }` and mutation process1 successfully `CellWritten { key:19, value:v }` for the **same exact numeric value v**. Each arm must have **exactly one qualifying write to its target cell after the read**; no inferred or external writes count. A read without the matching write is an unexposed or negative functional opportunity, not a positive. This is explicitly about address causality, not proof of emergent self-maintenance.

The **pre-registered source specificity control** repeats the same contrast under `mutate-g1`: graph2 tag must remain 11, and a successful write to cell19 following a graph2 tag11 read is *not* attributable to a changed graph2 source. `mutate-both` may be measured descriptively but is not an independent replicate of a single-target intervention.

## Frozen ecology and comparisons

- **192 new independent seed-worlds**, exactly `2,300,000..2,300,191`, disjoint from all previous Studies 14, 22 and 25. No eligibility filtering. Same external preauthored nine-instruction neutral prefix, same three-process pseudorandom continuation (18 LCG draws per process), same program semantics, 56 credits per process, 27 charged prefork attempts, strict cells=32/maxnodes=40/total storage=192 as in Study25. Exact prefork state is forked to each branch.
- **Seven matched arms** per seed, exactly **1,344 paired runs**, **8 externally clocked epochs ×12 charged attempts**, **10,752 individually hashed epoch snapshots**. Eight epochs cover the precommitted early exposure window only; do not call this a two-late-window maintenance test.
- Fixed branches: `control`, `sham` (externally rejected DropGraph0), `mutate-g1` (DropGraph1 + PutGraph1 with only node0 replaced by Halt/tag19), `mutate-g2` (same on graph2), `mutate-both` (both handles in order), `exact-original-g2` (DropGraph2+PutGraph2 exact unchanged object, must preserve simulated final state versus control), and `zero-credit` (external SetCredits 1–3 to zero at epoch0). All original code layouts, owner/reader ACL and storage budgets otherwise unchanged. No exogenous compute refill in this experiment.
- Report `GraphTagRead` and `CellWritten` successful native events, source-owner/reader/PC/tick/actor/epoch. A read may occur even if the program ultimately traps; only successful read and successful output events satisfy the primary outcome. Also report graph2 read exposure **denominator** among 192 worlds, the strict branch-wise output patterns, paired concordance/disagreement, and distinct-world proportions with 95% Wilson intervals. Do **not** count paired arms as independent seeds.

## Mechanism positive controls and integrity

Before interpreting ecology, run a **hand-authored separate positive calibration** in which an externally initialized CIL reader uses a foreign graph's `GraphReadTag` result directly as the register index for `Op::Write.address`, with a fixed value. Same-object external code replacement from original GraphNew/tag11 to Halt/tag19 **must** redirect a successful output from cell11 to cell19 while preserving the numeric value. The same-object unmodified reinjection control must leave output at cell11. This synthetic control is a mechanical validation only and must never be counted in the independent ecology denominator.

Reject the entire technical run if any of 1,344 branches is missing, source mutation/intervention order differs, any `PutGraph` failed, prefork hashes differ within seed, sham/exact-original simulated states differ, zero-credit executes, original graph2 source tag is not 11, strict resources are violated, event source ancestry is inconsistent, any SQLite epoch hash differs, or Rust exact replay/independent Python audit fails. Synthetic negative fixtures exclude wrong actor, wrong graph, changed output **value** but unchanged output **address**, write preceding the read, missing target read, and wrong epoch.

## Interpretation and stopping

Even a positive result would show **source-content-sensitive native CIL output-address control** under external code modification in previously externally initialized machinery—not internally invented functional organization, repair after damage, closure, autonomous energy acquisition, or cyberlife. The primary 192-seed results, including complete nulls, must be archived without outcome-dependent changes. No `REPAIR/FITNESS/REPRODUCE` opcode or host-selected favorable mutations. **CL-1 remains unaccepted without later endogenous two-component causal function and internally initiated restoration in separated windows.**
