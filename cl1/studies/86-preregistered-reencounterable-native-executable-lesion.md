# CL-1 Study86 — prospectively registered re-encounterable native executable lesion

**Status: NEW preregistration, before Study86 stochastic outcomes. ZERO Study86 sampled worlds at registration.**
Study84's original native lesion-to-PC3 produced E10/L1/R0 across 128 fresh genotypes, but explicit host repair was also R0; Study85's **retrospective** full-source audit found that the sole lesion-positive original seed 5,700,098 remained alive with 72 local credits at PC5 and did not revisit damaged PC8 even after the host restored PC8.next to9. This is a fundamental confound: restoring an unreachable code edge is not restoring executed function. Study86 changes one predeclared lesion **to a fixed PC8→PC8 self-loop**: the damaged executable code site itself remains on the actor's execution trajectory. This is a NEW independently seeded prospective study, not a tuned rerun or a reclassification of Study84.

## Frozen population, baseline program and physics

Use the exact source-committed fully scrambled **per-draw SplitMix64** Stage82 generator and eight-bin 28-node CIL random grammar with generic native `PatchNext(node=R1=8,target=R0,next=pc+1)`; no privileged repair instruction, engineered mutation success, lesion detection or organism repair scaffold. Exactly **128 fresh, unique full-code genotypes**, integer seeds **5,800,000..5,800,127**, no cherry-picking, resampling or post-outcome revisions; independently rebuild the complete generator output for each initial seed. Baseline setup R1=8, R2=7, R3=9, 64 original local process credits, `World::with_strict_capacity(4,32,64)`, common pool96, externally supplied source3 or8, opt-in recoverable Draw physics and charged environment-pool-paid Draw, and native real executable edge events. All world laws are human-designed substrate, never self-created energy.

Exactly 6 **common real pre-fork global epochs0..5**,12 charged opportunities per epoch and external +8 common-pool credits per epoch≥1, independent low/high source per seed. Retain the entire original native code, actor PC, registers, historical events and resources at checkpoint end of global epoch5, then fork six matched post-treatment arms from the **byte-identical source-specific pre-treatment world snapshot**. Native mutation-disable mode is set **only after** the source-specific fork, never during pre-treatment.

## Frozen, outcome-blind pretreatment exposure and lesion

The same exact source-based native-execution exposure gate as Study84: successful internal Read(key7)→register-R0→Write(key9) in both source variants, same native writer PC and same arithmetic offset yielding high-low +5, and the actual executable code location PC8 traversed between that read and write, with a concrete mutable single next edge at the fixed pre-treatment checkpoint. No-exposure seeds retained in 128 denominator.

At postfork epoch0 (global epoch6), if and ONLY IF both source worlds meet E, the experimental host applies **External PatchEdge(actor1,node8,next8)** rather than Study84's target3. No-op if the real checkpoint next edge was already8; an ineffective lesion is not counted L. This lesion is generic structural rerouting to self, and the actor will re-encounter the same changed PC8 **if it is already on its control path**. No mutation detection, targeted actor credit gift, source-special repair or fitness policy is added.

## Six fixed matched postfork arms per source and 18 epochs

Exactly the same six arms as Study84, source-specific fork:
1. intact, native edits allowed, no host code mutation;
2. sham, host PatchEdge PC8 to exactly checkpoint original next edge;
3. lesion-native, host PC8→8, native edit allowed;
4. lesion-edit-disabled, host PC8→8, native edit suppressed (full original opcode validated and charged);
5. lesion-host-restore, host PC8→8, native mutation disabled, host **at postfork epoch4 (global10)** restores the exact checkpoint PC8.next edge without actor reset/credit gift;
6. lesion-draw-ablated, host PC8→8 and no usable common pool in any postfork epoch (secondary resource intervention, not matched energetic treatment).

All non-draw-ablated arms receive the identical outside **+8 common pool credits per postfork epoch including epoch0**; the ablated arm has externally set pool0 per epoch. All origins logged and snapshot-hashed. **128×2×6=1536 complete native postfork runs** with **18 full-state snapshots per run=27,648 SHA256 records**, exact deterministic Rust replay, independent Python reconstructed genome, original pre/post event-prefix, code-edge edit ancestry, source-to-output register provenance and credit conservation.

## Prespecified outcomes and required positive-control logic

- **E** (pretreatment functioning and actual PC8 traversal) numerator /128, unchanged from Study84.
- **L**: in first postlesion global epochs6..9, source-sensitive native function at originally matched writer PC/offset disappears in **both** lesion input streams while the corresponding **sham** retains it under both inputs. Report L/E and L/128.
- **External assay positive H**: among L seeds, fixed external restoration at global epoch10 yields same original source-conditioned native function in BOTH nonoverlapping late windows global10..15 and16..23. Count H/L; **H is never native self-restoration**. Even if stage-level H>0, examine which L cases actually qualify for interpretable internal restoration.
- **Endogenous code-edit-associated restoration R**: among L with a responsive external assay (H), require native function in BOTH late windows (same source low/high +5, same original writer PC/offset), **actor-executed effective PC8 executable edge edit AFTER lesion BEFORE qualifying output**, mutation-disabled controls lack original functional output in corresponding windows (each input separately), and no host repair or hidden credits. Report R/L, R/H, R/128, the all-world 128 denominator and every no-exposure/ineffective-lesion case. If H=0, R is **NOT CAUSALLY EVALUABLE**; do not silently translate into an informative negative proof.
- **Mechanism trace**: native event-PC and original+mutated code, no-op vs successful edit, resource Draw success (not DrawDeferred), actor still running and re-encountering PC8 after lesion, host-positive code edge and source def-use; distinguish transient restart from two-late-window restoration.
- **Interpretation**: Native actor code modification by a random genome is not necessarily adaptive, self-selected, beneficial, intentional or alive; this is only an isolated source-output function. CL-1 requires at least two reciprocally causally maintained components plus function inheritance before stage acceptance.
