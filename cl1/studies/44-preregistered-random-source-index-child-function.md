# CL-1 Study44 — prospectively registered generic source-index diversity and functional child opportunity

**FROZEN BEFORE RUNNER / AUDITOR / NEW SEED OUTCOMES.** Study43 retrospective analysis (after observing Study41/42) showed that all successful children merely executed GraphNew, with no child native CellWritten in either cohort. This experiment gives stochastic CIL more *general* node-source diversity, **without inserting any hand-chosen useful executable node**, repair, fitness, reproductive objective or host-created offspring.

## Question and scientific boundary

Does allowing an ordinary seeded random native `Const` to place a **general code-node index** in source register2 create a measurable opportunity for native `GraphCopyNode` and `GraphLaunch` to yield children that successfully execute something other than `GraphNew`, especially real `CellWritten` operations? An increased child output is only **functional opportunity**, not heritable self-maintaining organization, because parent code, ambient compute and starter policy remain externally supplied.

## Interpretation

If non-GraphNew child instructions or shared outputs occur prospectively, they demonstrate **native generation of executable offspring with expanded generic instruction repertoire**, but may be ephemeral, accidentally equivalent to parent outputs or directly powered by host. Require *separate* independent reproduction and genuine parent-lesion/self-repair causality experiments before declaring endogenous organizational heredity or life. If none occur, report the negative without adding goal-directed generator biases.
