# CL-1 Study105 Phase0 — narrow native PatchNext-only suppression for real self-copy causal controls

**PRE-IMPLEMENTATION, zero ecological genotypes.** After the source-pinned [Study104 native functional heritable mutation](../results/study104-verified-native-functional-allele-inheritance.md), a causal-control gap remains: the existing `with_native_code_edits_disabled` blocks generic `GraphCopyNode` and executable copying as well as `PatchNext`; using it on a self-replicator would destroy offspring by suppressing *reproduction*, not isolate inherited mutation. A source-code-different Const substitution is useful for mechanism calibration but cannot support a strict same-initial-genotype mutation-only causal contrast.

## Preregistered generic VM law and cost semantics

Introduce one **disabled-by-default, explicitly serialized** world configuration `with_native_patchnext_disabled()`. It suppresses **only successful native `Op::PatchNext` changes to executable code**, while preserving exact ordinary charge of the attempted native instruction, native instruction next-PC, and every other existing CIL behavior. `GraphNew`, `GraphCopyNode`, `GraphLaunch`, `GraphEncode`, other graph mutations, resource uptake and ordinary Read/Write remain functional. One native `NativeCodeEditSuppressed { opcode_tag: 6 }` observer event records a valid, charged and suppressed PatchNext; it must not masquerade as `ExecutableEdgePatched`. Original `PatchNext` invalid register, target edge, code node and permission semantics must still trap, consuming exactly the ordinary attempted instruction charge. Internally validate by running the unmodified opcode on a private shadow World with all suppression flags disabled, discarding shadow code mutations and side effects. Do not expose shadow state to CIL. Under `with_native_code_edits_disabled`, existing broader suppression precedence and original behavior must remain backward compatible. Default false must preserve old serialized state hashes and source-pinned historical results.

All results are researcher-authored fixtures and count as **zero independent ecological genomes**.
