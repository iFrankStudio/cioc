# CL-1 Study56 — preregistered fresh-seed replication of Study55 generic native branch topology

**Prospective replication registration BEFORE code, sampling, and outcomes.** Study55 is known: in 256 fresh correlated seed pairs, random uniform-prefix `Branch.nonzero` generated strict native copy→edit→launch graph assembly in 2/256 worlds versus0/256 under fixed local `index-2` backedges, while functional native child `CellWritten` was zero in both. The single-study 2/0 direction is **weak**, may be sampling noise, and must not be presented as established effect. This experiment independently evaluates it, without seed tuning or changing the prior frozen effect definition.

## Exact independent ecology

- Exactly **256 new independent paired seeds**, ID **3,900,000..3,900,255** inclusive, no seed selection. Two CIL graph-topology variants × four original environment arms each, **2,048** exact native runs, **49,152** full SHA256 hashed epoch snapshots.
- Repeat Study55 *byte-for-byte* for both `local` and `uniform` native program creation, world capacity, initial three processes, 27 prefork charged attempts, 24 epochs×12 charged attempts, exact 9-op scaffold, 72 stochastic continuation nodes9..80 and terminal Halt node81, same 24-way opcode generator and all operands, same CIL VM and kernel. Only accepted differences versus Study55 are study identifier, filenames, **independent seed start** and source-revision reporting.
- For all original actors and every continuation: exactly the same Study55 64-bit wrapping LCG; one draw for opcode%24, an extra draw for choice8 source-index%81, and an extra draw for choice9 `Branch` **in both code variants**. `local` ignores choice9's draw and uses `nonzero=index-2`; `uniform` uses `nonzero=(draw%index)`. No other grammar or topology differences.
- Four matched environment conditions per regime exactly `ambient-general`, `ambient-only`, `closed-general`, `zero-credit-ambient-general`: ambient +8 **external** pool credits at epochs1..23 when enabled; a uniform, code-blind host starter transferring one already-existing pool credit to the lowest ID unstopped zero-credit actor iff no runnable actor; zero-credit at epoch0 only in zero-credit arm. One native instruction still costs one total compute credit. Within-regime four arms start from byte-identical prefork world; initial programs are deliberately nonidentical across regimes only at Branch targets.

## Frozen primary endpoints

**A — strict spontaneous CIL graph assembly:** worlds/256 in `ambient-general` where a native original parent successfully `GraphNodeCopied` a nonzero source-code index into graph G, then successfully `GraphNodeEdited` G, then successfully `GraphLaunched` the same G into a native child, in strictly ascending ticks and with exact same-parent, same graph, Internal actor/owner and child provenance. Count each paired regime, four discordance classes `uniform-only`, `local-only`, `both`, `neither`; Wilson95 for arm rates. **Directional replication criterion** (registered): `uniform-only > local-only`; if not, report null/reversal. No stopping after seeing a positive seed and no aggregation of original Study55 into the registered denominator.

**B — actual child native functional shared output:** worlds/256 with at least one internally successful native-launched child `CellWritten`, authentic prior `GraphLaunched`, child executable `Write` at PC, correct origin/actor/cell/value. This remains a separate frozen primary. Zero remains valid.

## Scientific meaning

A successful replication would confirm only a **native programming-language control-flow opportunity** to construct graph-code sequences, not a viable child, self-maintenance, repair, growth, inheritance or evolution. Study55/56 remain correlated paired seeds *within* each experiment and independent between experiments. No organism-specific host rescue, REPAIR/FITNESS/REPRODUCE opcode, scripted native graph builder or preselected favorable source node.
