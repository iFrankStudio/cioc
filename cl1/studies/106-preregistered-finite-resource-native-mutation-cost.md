# CL-1 Study106 — prospective same-genotype native functional variation cost under finite shared computation

**PROSPECTIVE; no Study106 results existed when this document was committed.** This is a **researcher-engineered evolvable chassis** experiment, NOT random emergence of replication or life. Source-frozen prior mechanism: verified Study104 genuine actor-native fast/slow executable mutation inherited in branching daughter programs; verified Study105 added opt-in PatchNext-only ablation that **does not disable GraphCopyNode/Launch**, permitting a same-CIL-genome causal counterfactual. The scientific question is whether enabling actor-native **functional inherited mutation** changes finite-resource native reproduction versus disabling only PatchNext for the *same exact starting CIL program*. This tests variation costs, not Darwinian adaptation.

## Frozen new initial CIL genome cohort and environmental setup

Exactly **32 previously unused genome seed labels** `6,100,000..6,100,031`. For each seed independently derive SplitMix64 bytes with the standard 64-bit mixing constants (gamma0x9e3779b97f4a7c15, mul0xbf58476d1ce4e5b9, mul0x94d049bb133111eb, xor shifts30/27/31) and use successive mixed values to select **two functionally meaningful initial-code parameters**: `slow_loop_count=1+(draw1 % 32)`, `native_draw_and_child_grant=320+(draw2 % 161)`. Use ordinary, fixed 28-node Study104 CIL scaffolding with **only** PC24's Const R1=slow_loop_count and PC20's Const R2=draw/grant modified by the deterministic generator. All other 26 nodes, initial PC4.next5, actor-native PatchNext at PC8, shared toggling input cell11=5/24, graph full-copy, native Draw and native GraphLaunch remain exactly as in Stage104. Source input remains key7→key9 at native actor PCs2/3. The 32 seed labels are fixed regardless of outcome; report all code-hash duplicates if any, and do not resample candidates for desirable phenotype. These 32 seeded *template variations* are **NOT independent origin-of-life experiments** or a random sample of CIL programs.

Every matched arm begins with the **same exact byte-identical initial CIL code for both founder processes** ID1 and2, each with 500 local compute credits and initial PC0, strict world capacity `with_strict_capacity(4,64,1024)`, native `pool_paid_draw`, native `recoverable_draw_shortage`, and observer-only `with_native_executable_edit_trace`. External setup is limited to SetCell(key7=3 or8), SetCell(key11=5) and SetComputePool(2400). No later environmental changes, host process credits, code restoration, graph injection or fitness assessment.

## Four precisely paired native worlds per seeded genotype

- `native-edit-source3`: normal native PatchNext and source3.
- `patch-disabled-source3`: **identical initial code**, but opt-in generic `with_native_patchnext_disabled()` world law; attempted PatchNext is charged, validated, tracked with NativeCodeEditSuppressed, does **not** change code; generic graph copy and reproduction stay operational.
- `native-edit-source8`: normal PatchNext, source8.
- `patch-disabled-source8`: exact genotype with narrow ablation, source8.

No source-code-different Const controls are used for primary comparison. Exactly **8 epochs ×250 maximum native charged attempts** per world (2,000 max), no epoch intervention; source code behavior, storage, scheduler and public pool are held fixed. 32×4=**128 original runs**, expected **1,024 exact SHA-256 SQLite epoch snapshots**, with full Rust deterministic replay and independent read-only Python verification. Processes that halt, trap, fail to receive pool credits or never reproduce stay in the denominator. No early-stop or surviving-genotype selection.

## Frozen measurements and evidence hierarchy

**Resource and source ancestry:** all aggregate compute inventory equals initial `1000+2400=3400 - actual charged native attempts`, no process-negative balance, exactly five initial external actions (two loads, two cells and pool). Successful CellWritten(key9) must have an actual same-actor previous CellRead(key7) with matching value, and descendant code generation must be traced to ordinary native GraphNodeCopied/GraphLaunched, never the host. Every native actor mutation event must be PC8/code node4 with before/after among5/24; mutation-only-disabled group must produce zero such events and all unmodified inherited fast PC4 edges while still permitting real native births.

**Prerequisite exposure E:** source3/8 matched actor writes retain correct source-dependence in original founder and at least one descendant, and an enabled world has a genuine post-load nontrivial native `ExecutableEdgePatched` followed by a complete28-node native self-copy and a real child that inherited that changed PC4 route. Derive child birth genotype by deterministic event replay from parent changes, then verify that at least one slow-born child actually follows PC24..27 before its first PC5, and fast-born children skip that path. Report E/32; no exposure is NOT positive evidence of selection.

**Primary intention-to-treat endpoint:** difference in total internal native child launch count per seed, enabled-minus-patch-disabled under the **same source** at the fixed 2,000-attempt horizon. Report all 32 paired differences for source3, source8, their full exact discordant/tie counts and paired sign tests (two-sided); treat the two source versions of one genotype as dependent matched conditions rather than 64 independent genotypes. Because a fixed **attempt horizon** gives slow path more steps per child, an enabled run's lower births can be a **direct instruction-cost consequence** rather than environmentally selected adaptation; do NOT call it natural selection. Report how many actual offspring inherit each allele and execute it at birth, and how many reproduce themselves. Do not predeclare a favorable direction, and do not enlarge seed range based on results.

**Secondary:** same-world lineage output variation and child code PC4 ancestry from actual original event sequence, native Draw(positive) before each child, launch resource conservation, total initial code-genome hash distinct count, real total attempts and trap reasons. Independently audit all original 1,024 serialized epoch hashes, source revision and complete event stream. Verify robust mechanism with no mutation-only false positive or hidden VM helper.

**Decision:** If the native-vs-disabled contrast differs, it is evidence about **fitness costs of an investigator-coded mutation generator in finite resource worlds**, not broad Darwinian selection. A later independent design may test environmental selection under freely arising diverse mutations, but Study106 alone cannot establish spontaneous genesis, open-ended evolution or two-component organization. All 32 initial genomes have a researcher-designed common complete self-replicator chassis; **CL-1 remains OPEN.**
