# CL-1 — Endogenous Organization Research

**Status: nineteen independently seeded ecological cohorts executed (Studies 01–14, 22, 25, 27, 29, 32). Study 27 independently verified single-source code-tag-to-write-address dependence in 2/192 worlds, now strengthened by Study31's register def-use audit. Study29 found 0/256 complete two-source additive outputs. Study32 observed native compute-pool uptake and 86/192 worlds exceeding original execution credits without postfork external process refill, but untreated W3 activity remained 0/192. Technical Studies 15–21, 23–24, 26, 28, 30–31 do not add independent seed cohorts. CL-1 positive milestone NOT accepted.** CL-0 is already accepted as laboratory infrastructure. CL-1 is a scientific program, not a new name for the VM.

- [Study 19 preregistration](studies/19-preregistered-external-graph-control.md) — verified [structural positive-control checkpoint](results/study19-checkpoint.md): external-only `PutGraph` restores exactly the removed graph within strict resource accounting and SQLite epoch replay. **Functional restoration and endogenous maintenance remain unproven.**
- [Study 20 preregistration](studies/20-preregistered-functional-assay-calibration.md) — [verified functional calibration](results/study20-checkpoint.md): scripted two-graph CIL readout fails after single/double deletions, returns after explicitly external reinjection, and changes predictably when external code content changes. **No autonomous multi-epoch recovery or endogenously created organization was shown**.
- [Study 21 preregistration](studies/21-preregistered-temporal-restoration-calibration.md) — [source-verified temporal positive-control checkpoint](results/study21-checkpoint.md): two graph-dependent outputs lost in the first observed epoch; explicit **external** same-object restoration recovers the function in two subsequent independently measured windows. All code and probes are investigator-authored; **no native recovery or life evidence**.
- [Study 22 preregistration](studies/22-preregistered-compute-limitation-ecology.md) — [verified fresh-seed result](results/study22-checkpoint.md): external compute recharge raises late W3 active worlds to 57/96 and cross-owner code copies to 15/96, from 0/96 untreated, but there are 0/96 late successful native cell writes and no demonstrated autonomous recovery. **Exogenous compute is not endogenous energy acquisition**.
- [Study 23 preregistration](studies/23-preregistered-graph-read-provenance.md) — [verified read-source provenance checkpoint](results/study23-checkpoint.md): `GraphTagRead` and `GraphFieldRead` now identify which code-bearing graph, actual source owner, node and value were successfully read, with no new VM capabilities. **Causal value-dataflow and endogenous design remain unproven.**
- [Study 24 preregistration](studies/24-preregistered-foreign-graph-read-output-audit.md) — [verified source-read exposure checkpoint](results/study24-checkpoint.md): under external recharge, 11/96 historical seeds showed late foreign graph-code reads, but 0/96 showed the same actor's later successful cell write. Reuses Study 22 seeds; no new independent ecological samples, and **output value causality NOT EVALUABLE**.
- [Study 25 preregistration](studies/25-preregistered-prospective-code-content-causality.md) — new 96-seed prospective intervention to distinguish exact graph-code content sensitivity from mere graph presence. **Do not treat preregistration as an outcome.**
- [Study 25 source-perturbation results](results/study25-checkpoint.md) — 96 **new independent** worlds, 864 matched runs and 20,736 verified SQLite snapshots: no matched changed source-tag and successful changed numeric cell output; 3 source-related output-dropout candidates require strict cause classification, not automatic causal acceptance.
- [Study 26 preregistered exploratory plan](studies/26-preregistered-retrospective-dropout-audit.md) — known-after-Study25 dropout classification only; explicitly **reuses the same world IDs** and cannot increase independent sample size.
- [Study 26 post-outcome exploratory mechanism checkpoint](results/study26-checkpoint.md) — three previously known graph2-mutant missing-cell11 events all read changed tag19, none wrote original cell11; two trapped and all wrote other cells. **Explicitly not prospective confirmation**.
- [Study 27 prospective preregistration](studies/27-preregistered-graph-tag-address-relocation.md) and [verified independent replication checkpoint](results/study27-checkpoint.md) — 192 new independent seed worlds, 1,344 matched runs, 10,752 verified snapshots; in 2/192 worlds, changing graph2 code tag11→19 redirected a successful same-process output from cell11 to cell19 **without changing its numeric value**. **Source-dependent I/O is observed, but autonomous design, two-component closure and maintenance are not.**
- [Study 28 registered retrospective audit](studies/28-registered-retrospective-second-component-audit.md) — [verified second-source checkpoint](results/study28-checkpoint.md): of two known graph2-dependent outputs, one showed graph1 intervention interference, but neither showed the required earlier native graph1 code read; no proved second read-mediated component. Corrected per-seed Study27 preserved values are 1 and 4.
- [Study 29 prospective new-seed protocol](studies/29-preregistered-independent-dual-source-arithmetic.md) — [verified negative checkpoint](results/study29-checkpoint.md): 256 independent worlds, 1,792 paired runs, 14,336 exact epoch snapshots; graph1 read in 38/256 and graph2 read in 45/256 untreated epoch0 worlds, but **0/256** complete paired additive-source output functions.
- [Study 30 registered *post-outcome* diagnostic](studies/30-registered-retrospective-dual-source-pipeline.md) — [verified native read/Add/write bottleneck](results/study30-checkpoint.md): 4/256 existing seed-worlds successfully read both sources in epoch0, **0/256** subsequently executed a successful Add on that path, while 116/256 had native writes elsewhere. Reuses Study29 seeds; **no additional independent ecological samples**.
- [Study 31 registered retrospective register lineage](studies/31-registered-retrospective-register-lineage.md) — [verified def-use checkpoint](results/study31-checkpoint.md): both previously known Study27 seeds passed stricter native `GraphReadTag.dst=0` to `Write.address=0` register lineage, without an intervening overwrite. The numerical outputs were 1 and 4 in the two separate seed-worlds; **zero new independent worlds** and no autonomous maintenance evidence.
- [Study 32 preregistered native resource-uptake ecology](studies/32-preregistered-native-compute-pool-uptake.md) — [verified resource-accounting and W3 null checkpoint](results/study32-checkpoint.md): 192 new independent worlds, 1,152 matched runs and 27,648 exact SQLite snapshots. Native pool draw in W1 154/192; internal uptake extended execution beyond the original 47-credit budget in 86/192. **W3 without exogenous refill 0/192 active worlds; no self-sustaining life claim.**
- [CL-0 → CL-1 handoff](../cl0/docs/CL-1-handoff.md) — scientific boundaries, controls and research acceptance rule.

**No life evidence has been established.** Across nineteen distinct independent ecological study cohorts (2,304 initial worlds and 13,536 matched runs), rare mutual state effects and external-compute-supported persistence were observed, but registered restoration and organizational closure were not. These distinct seeded generator families must not be pooled for statistical inference. See [results](RESULTS.md).
