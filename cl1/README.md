# CL-1 — Endogenous Organization Research

**Status: twenty independently seeded ecological cohorts executed (Studies 01–14, 22, 25, 27, 29, 32–33). Study 27's 2/192 source-code-tag-dependent outputs have native register def-use evidence (Study31); Study32 observed native compute-pool uptake and finite budget extension in 86/192 worlds. However, the preregistered new-seed Study33 combining both pathways found 0/128 source-register-qualified output-plus-native-Draw opportunities and 0/128 matched source-content-sensitive extended functional outputs. W3 without external refill remains 0/128. Technical Studies 15–21, 23–24, 26, 28, 30–31 are not new independent worlds. CL-1 positive milestone NOT accepted.** CL-0 is already accepted as laboratory infrastructure. CL-1 is a scientific program, not a new name for the VM.
