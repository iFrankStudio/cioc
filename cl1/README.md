# CL-1 — Endogenous Organization Research

## Current verified frontier (original Studies88–94, 2026-11-14)

- **A real stochastic native function can now be damaged with causal controls**, but no internally restored random function has passed the strict gate. Study88 [original CI43597236032](https://github.com/iFrankStudio/cioc/actions/runs/43597236032): fresh128 genomes, E1/L1/H1, endogenous R0. Retrospective Study89 [CI43597746883](https://github.com/iFrankStudio/cioc/actions/runs/43597746883) proved that its PC8→PC8 injury trapped the only actor at a non-edit instruction: the absence of repair there was *structurally predetermined*, not evidence of biological inability.
- **Native editing can be reachable after code damage**, verified with a zero-new-genome HUMAN-scripted Study90 [CI43598015017](https://github.com/iFrankStudio/cioc/actions/runs/43598015017). Fresh Study91 [CI43598229363](https://github.com/iFrankStudio/cioc/actions/runs/43598229363) then found E2/L0: preserving code-edit reachability alone did not actually break the source function. Study92's read-only original-hash [CI43598614881](https://github.com/iFrankStudio/cioc/actions/runs/43598614881) confirmed both E actors left the damaged PC and one had real native PatchNext opportunities, while sham dropout/noninterrupting damage explained L0.
- **A direct source-writer bypass supplies a real immediate loss while preserving a route**, shown in a human-authored Study93 fixture [CI43598882188](https://github.com/iFrankStudio/cioc/actions/runs/43598882188). Independent prospective Study94 [CI43599692512](https://github.com/iFrankStudio/cioc/actions/runs/43599692512) fully verified **512 new original genotypes, 6,144 native matched worlds, 110,592 exact full-state SHA256 snapshots**, yielding **E1/L1/H0/native R0**. The external code edge was restored at epoch4, but it did not meet the frozen two-late-window functional recovery criterion. Its sole registered causal case awaits separate *retrospective* native state/PC lineage diagnosis.
- **Formal source-level ceiling:** in the Study82–94 fixed eight-way CIL genome grammar, native executable mutation can alter only one existing PC8 edge (at most28 executable graph configurations); no native graph creation, spawning or heredity exists in that grammar. See [bounded genome proof](analysis/fixed-single-edge-plasticity-structural-ceiling.md). Further scale-up cannot by itself establish open-ended evolution. **CL-1 remains OPEN.** Hand-programmed repairs and retrospective audits add **zero independent ecological genomes**.

**Latest verified (2026-11-14):** Study80's ten human-scripted native edge restoration fixtures and 120 exact snapshots passed [focused CI](https://github.com/iFrankStudio/cioc/actions/runs/43591338076), proving VM feasibility only. Study81's LCG-low-bit modulo-8 generator **failed** its unique-genome gate at seed5,400,026 and was correctly aborted [CI](https://github.com/iFrankStudio/cioc/actions/runs/43592644179). Study82 used a separately preregistered fresh 128-genotype per-draw SplitMix64 cohort; 512 matched native worlds and 12,288 original epoch hashes [passed CI](https://github.com/iFrankStudio/cioc/actions/runs/43592985831). Actual actor-native executable graph edits occurred in **57/128 low-source and 59/128 high-source** genomes, source-tainted W2 functions in **17/128**, and W2+native Draw+preceding native executable edit coexistence in **4/128**. The independent original-corpus retrospective Study83 [passed CI](https://github.com/iFrankStudio/cioc/actions/runs/43593454995) and showed W2 **17/128 edit enabled versus 23/128 edit disabled** (enabled-only2, disabled-only8, paired p=0.109375) and late-W2 4/128 vs5/128: no proven adaptive benefit of stochastic mutation. These results establish bounded native code plasticity and function/energy co-occurrence, **not spontaneous damage recovery, internal organizational closure or cyberlife. CL-1 remains OPEN.**


**Subsequent source-pinned native-damage gate (2026-11-14):** Study84 separately preregistered **128 fresh stochastic genotypes**, performed **1,536** common-pretreatment matched runs and **27,648** verified postfork hashes [CI](https://github.com/iFrankStudio/cioc/actions/runs/43594558556): actual source-function exposure **10/128**, effective native-code lesion **1/128**, strict internally restored function **0/128**, and qualifying external-host-restored function **0/128**. Study85's post-outcome original archive [verification](https://github.com/iFrankStudio/cioc/actions/runs/43595235138) traced the sole effective-lesion seed's actor **alive at PC5 with 72 credits** when the host restored the original PC8 edge: the actor never revisited the repaired node and generated no subsequent source reads or writes. [Retrospective diagnosis](results/study85-original-host-restoration-not-functional.md). **Stage84's recovery assay lacks an informative functional positive control.** A distinct [Study86 self-loop / re-encounterable lesion protocol](studies/86-preregistered-reencounterable-native-executable-lesion.md) was therefore frozen for a new cohort; no unverified outcome is counted as success. CL-1 remains OPEN.
