## 1. 为什么这次不是 G1 的重复

G1 已证明原始 PID1 能执行研究者预先写死的普通 CIL Branch，但不能通过当前 `PatchNext` 直接修改 Branch 的非零/零去向。G2 改为由 PID1 使用真实付费的 `PatchConst PC28` 修改自己在 PC173 的**可执行 Const 参数**。下一次监控阈值到来，原生 PC173 读取新参数、PC174 计算当前输出与参数之差，PC175 按结果真正选择继续学习额度恢复或跳过；PC26 还真正执行 `PatchNext` 拆除监控。

这条执行链**不依赖实验宿主来替 PID1 改源码或决定分支**。程序在 180 个源槽已满的情况下复用原错误终止节点 PC25..28，并将原三次失败的 PC15 停机出口直接接到原生 PC61 Halt；严格 **16 个数据单元、180 个源码槽、300 总占用、每个单独 PID1 6,000 条私有付费 CIL 指令**均未改变，所有真实反馈仍由实际 `Write11 → 外部置 cell20 → 付费 Read20` 交付。

但其*规则本身*（何时修改、如何比较上一次成功猜测、是否恢复额度）完全由研究者在初始化源码里指定。G2 只能证明个体**自主执行已编入的自修改操作**，不能证明自行发明或优化了一套新算法。

## 2. 已由原生轨迹证明“修改 → 后续读取 → 行为改变”

在四种同结构 G2 程序里，只有 `PC175 Branch` 初始非零/零去向不同。主 `G2_changed_allow` 程序：将上一次真实经历的任务猜测 `r3` 写入未来 `PC173 Const.value`。这样下一次到达该规则时，条件已从初始 `theta=0` 变为自身上一轮写入的值。

全部 45 个新真实任务世界中，主程序发生：

| 原始世界内可审计事件 | 数量 |
|---|---:|
| 真实原生 PC175 付费条件判断 | **27** |
| PC28 真实 `PatchConst` 改变 PC173 的值（非同值重写） | **15** |
| 修改后的 PC173 值之后重新被正常 CIL 执行读取 | **8** |
| 已逐行核验、与继续使用初值 theta=0 时的*局部分支*相反的原生例子 | **6** |

例如 [原始 g2_persistent_drift_two_shifts_a0_d1 源码和寄存器逐步轨迹](https://github.com/iFrankStudio/cioc/blob/cl1b-ci-evidence/run-records/9cdbeb5f43b897f3f1ddd19fa0d8fc6c8d31404b-44917352841-1/cl1b_refill_rule_g2_original_g2_persistent_drift_two_shifts_a0_d1_G2_changed_allow.jsonl)：PID1 先付费将 PC173 参数由 0 改为 2；第 **1,376** 条付费指令 PC175 实际看到当前 guess=2、theta=2，选择**跳过额度恢复到 PC179**；若只将当前 theta 保持为初值0、其它此刻寄存器不变，分支会转向 PC176 恢复额度。已逐行核验另外五个这样的原生本地分支反转案例（分别在付费步 1539、1429、1585、1411、1611）。这是**真实受自身变异源码影响的控制流差异**，但对“保持初值后未来的整体世界如何分叉”的完整反事实仍需后续单独原生干预，不能仅凭这一局部分支差异声称全局因果净收益。

特别要注意：15 次**有效参数变更**只出现 8 次被下次监控逻辑重读的事件，表明不少付费自修改在24阶段生命周期内根本没有充分利用的机会。它对“短生命周期中能否摊销学习成本”的评估非常关键。

## 4. 科学解释与后续问题

**这轮真正增加的可复核事实：**同一连续 PID1 在有限原始 CIL 世界里，通过实际付费指令修改了以后会执行的源代码常量；改变在后续又被实际读取，并影响了原生分支选择。这比只在数据单元记录“我修改过”或实验宿主替它编辑源码更强，证明了特定原生程序的**带成本在线策略参数自修改闭环可执行**。

**这轮同样清晰的否定结果：**这个循环没有击败强固定基线。上次成功输出 `r3` 作为未来值得恢复学习的信号，缺乏可证明的预测力；完成一个生命周期内多次付费修改也没有自动变成有益的学习行为。且15次变更只有8次后续实际被重读，显示修改后的摊销空间有限。

**尚无证据支持：**个体自主构造了规则、发现最优反馈特征、估计未知变化风险、认证反馈来源、真实反事实收益学习、长期跨任务迁移、跨世界单个连续生命、开放式演化或CL-1B B3/B4接受。所有四种变异源图仍由研究者设计。针对参数变更效果本身，目前并没有**同源、同收费、只抑制PC28 PatchConst的独立原生因果对照**，不要把上表跨程序成本差归因于修改参数本身。

**下一次有判别力的突破点**应优先评估：能否用真实可认证反馈形成付费预测，并修改一个能够在更多后续任务中重复使用、摊销成本的策略参数，而不是继续增加人工写的条件规则。实验必须冻结新未见的环境分布，设完整按任务真完成数约束的原生对照；必要时对付费PC28源修改做精确同源抑制，不放松原生命硬约束；无胜利就如实记录。

**状态：原生可执行付费自修改参数 = VERIFIED；整体净优势相对 G2-never = FALSIFIED；CL-1B OPEN，B3/B4 NOT MET。**
