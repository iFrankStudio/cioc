Cutting output2's feedback successor prevents any genuine feedback Read and any retained correct candidate. Crucially, **BLIND_SUCCESS and INVERTED_FEEDBACK have the exact same initial CIL executable source and ordinary VM physics as INTACT**. Neither exercise authenticates the evaluator or prevents a dishonest bit20 provider.

## Scientific interpretation and stop/pivot

**Accepted narrowly:** real, externally provided true feedback has a causal impact on the existing B51c paid candidate search and resulting functional quality. The conclusion rests on actual native events with independent source-based replay, not the host's precomputed success flags alone. The original training circuit **node2→35→36→search continuation** is functionally necessary for the specific preauthored search algorithm and input schedule. These effects do not establish open-ended adaptation, new policy invention, endogenous task goals, or error recovery across new task families.

**Not accepted:** the complete B56-F1 experiment. F1a never asked one PID1 to build, compare or select two novel source-assembled monitoring strategies; it retained the original researcher-authored candidate generation algorithm, with two F1a arms modifying existing source routing. The original inventoried feedback monitor remains present in founder. B56 N56-A strict no-preexisting-all-monitor gate remains NOT MET, N56-B/C NOT TESTED, B3/B4/cyberlife NOT MET.

**Next source-inventoried F1 executable experiment** must freeze two independently assembled, structurally non-identical service-monitor graphs and same-PID actual source-paid trial windows, reveal all intentionally authored templates/branch predictions, track resource cost and truth provenance, include a **monitor-only** edit suppression after the original task search has already retained a viable program, and benchmark both fixed EVERY and FOURTH plus blind/stale external evidence and a task-informed oracle. A counterbalanced candidate trial order is required; a selector that always picks the cheaper policy when the environment provides no discriminatory information cannot prove ecological reasoning. If two generated graphs don't fit the original 4,000/180/300 finite budget, **record that feasibility failure rather than silently changing it**.
