## Native mechanism and what is really endogenous

One **logically continuous PID1** executes a **72-node researcher-written source controller**. Its first two arithmetic instructions (\`Add\`, \`Sub\`) are **disconnected self-loop templates**; input node33 initially points to itself, with no connected task-correct input→compute→Write route. It starts with finite **1,300 paid CIL instruction credits**, max16 data cells, max120 nodes and total strict storage **192**. Initial template node count grows only to **74** via **two paid \`CloneNode\`** operations; peak occupied storage is **83** units, never beyond cap.

Through paid CIL instructions, the same actor connects the two cloned arithmetic nodes to its normal task input/output, stores an offset parameter in its own charged data cells, traverses candidate offsets \`-3,-2,-1,0,1,2,3\`, switches from Add to Sub through code-edge \`PatchNext\`, and receives a single **external-origin success bit** at cell20 after each of two real actor-origin output11 writes on training probes **x=5** and **x=-3**. It must pay \`Read\` to access the bit. It retains a source route **only when both actual outcomes succeed**; CIL writes a real code-edge from task writer node2 back into an autonomous service loop. **No host source patch, credit top-up, winner selection, stop/restart or task label injection.** The task objective, binary evaluator, available operators, parameter enumeration and stop policy are nevertheless all **researcher-authored**.

The lab then presents heldout input cycle **[11,-7,0]** without any new feedback. Every genuine service output is counted against the frozen then-current task input and the externally hidden mode \`f(x)=s*x+k\`. Both truthful and sham arms use the **exact same initial founder graph, input order and 1,300 paid CIL budget** in every world. The sole sham difference is \`BLIND_SUCCESS\` receives the bit 1 on all training submissions even when false.

Independent JavaScript parsed the **actual Rust 72-op source literal** and executed all 16 TRUE/BLIND CIL worlds without reading native output values as inputs. It also validated the eight static-per-task source-defined output counts and patch-disabled summary. The same-source SHA was verified; missing source or mismatched rows cause the observer to fail closed.

Three critical remaining qualifications:

1. The **candidate generation grammar, ordering, correct-output evaluator and binary reward** are completely scripted by investigators, although the CIL actor itself pays to implement, trial, choose and keep code. Thus this is **engineered adaptive search**, not endogenous discovery of an adaptation policy or native intrinsic motivation.
2. Holdout values **11,-7,0** are new inputs within the **same affine family**, not unforeseen task families or nonstationary environmental shifts. The simulation does not demonstrate re-adaptation *after* retention when environment changes.
3. The strong static task-aware oracle remains more efficient than TRUE. Equal initial/realized 1,300 paid credits control energy exposure but do not equate instruction mix, source complexity, diagnostic overhead or the externally supplied information volume.

**Research result:** The B51b fixed two-candidate **2/8 structural coverage ceiling** was overcome through paid native parameter exploration and real evidence-guided source retention, proving a stronger engineered mechanism. This is a meaningful intermediate result toward B3, **not B3 itself**. No CL-1B B4 endogenous self-maintaining organization is observed.
