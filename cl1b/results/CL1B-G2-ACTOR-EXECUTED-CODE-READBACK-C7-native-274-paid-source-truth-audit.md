## 二、保持180满源码和全部物理不变的五处真实有费改动

所有原生世界仍然使用同一个CL0原始Rust内核、**单PID1、16数据单元、180源码节点、300总占用、6,000私人CIL指令账本、48真实隐藏任务**；不会暴露未来目标、免费读出宿主的源码状态、补额度或更改内核指令。由C6已有源码只变更PC24、PC28、PC52、PC79、PC173五节点：

```text
       PC173: Const r2 = actual_runtime_theta ; next -> PC24
       PC24 : Const r1 = 41                 ; next -> PC52
       PC52 : Write cell[r1=41] = r2        ; next -> PC174
       ...
       PC79 : Const r2 = 41                 ; next -> PC120
       PC120: Read r0 = cell[41]
       PC57 : Sub  r0 = r3 - r0
       PC67 : Branch(test=r0): nonzero -> PC27, zero -> PC125
               PC27 -> PC28 PatchConst(PC173, proposed r3)
       PC28 : PatchConst.next -> PC125  // no more optimistic Write40
```

核心区别是：**先实际执行原有源码节点PC173的Const并由其把真实数值装入PID1寄存器r2，随后才支付PC24+PC52，将该执行结果写进PID1数据cell41**。这不是通用源码快照、ReadCode、宿主认证或零成本传感器。它只能在**实际执行PC173之后**观测当前值：若修改后不再执行该节点，当前证据可能是**旧值**。本实验每次PC67门控都严格检查最新收费PC173→PC52执行次序和当前真实参数值，而不是假设无条件实时新鲜。

六臂均在同一冻结目标分别运行：
1. **G2_readback_attest**：个体自身付费执行PC173结果读回并依据比较执行修改或跳过。
2. **G2_readback_always**：与第1臂最初源码仅PC67零出口不同，付同样的监控费用，但始终执行有费PC28。
3. **G2_readback_abstain**：与第1臂最初源码仅PC67非零出口不同，仍付同样监控费，从不修改。
4. **G2_readback_pc28_suppressed**：与第1臂完全相同原始源码；只有**研究者**精准抑制PC28已收费修改PC173.value的效果，用于验证主体在下次真执行时能否读出**实际未修改**的标量。
5. **G2_readback_placebo180**：与第1臂完全相同原始源码，仅精确抑制不可达PC180的修改效果；全部逐条真实CIL及反馈必须与第1臂一致。
6. **G2_intent_mirror_C6**：C6历史真实源码作为**不同源**工程参照；不是第1臂的严格同源因果消融。

五个新源码节点在初始180槽内，所有其它节点、内核代码与物理资源都不变。每条真实服务只有实际执行了原生Write11之后，宿主才提供相应真实反馈至cell20。另四个`inverted/forced0`欺骗反馈世界不列为正确任务达成。

## 三、原始274世界实证：自状态真实读回成功，但不是实时无限能力

真实反馈的**45个C7 readback世界中**，PID1自行付费执行了**52次PC173→PC24→PC52真实常量值读回**，并真实执行**39次PC67修改分支、13次PC67跳过分支**。每一处付费gate的cell41与**实际当前物理PC173.value完全一致**；全部五种readback源码臂的门控真实源码不一致次数为**0**。代码从未借研究者之手注入正确`cell41`。

在相同初始源码的研究者修改抑制对照，实际发生**38次有偿PC28修改效果抑制**；其中有**19次后来的真实PC173执行→有偿Write41**，读到的实际值**与先前未成功修改的请求值相反证**，这个数量不是泛泛比较两个费用总数，而是[后验逐例见证审计](../audits/cl1b_g2_executed_readback_c7_failed_write_witness_audit.py)对每个CIL步骤的`suppressed_pc28.step/attempted/after`、实际`PC173`执行位置、`Write41`记录和下一次付费PC67的真实对应核验。**19/19个有曝光的已失效写入都有来源可核对的真实矛盾见证，0次把未成功安装的值保存成物理真实值**。此前C6意图镜像的错误并非所有原生个体必然无法避免。

但验证不是即时的。在这19次写入失效与下一次真实读回之间，实际消耗了**最少474、最高1921条**原始私人CIL指令，**中位数582条**。如果未来的实用决策发生在观察值更新之前，诚实记录也可能太迟；这不是对所有代码变异都能随时验真的能力。

被压制效果属于**人为研究干预**：研究者不允许修改真正生效、但仍照常向PID1扣费。C7没有证明能够识别恶意的内核、伪造的PC173执行值、外部反馈欺骗或额外运行期任意源码恶意更改；没有权限或密码学上的信任保证。
