# CL-1B B11 — prospective 30-world serial candidate-search path audit

**Evidence level: independent source-matched lightweight CIL interpretation, not native Rust execution.** The preregistration [B11](../studies/B11-serial-native-candidate-search.md) and [B11 Rust integration test](../../cl0/crates/world/tests/cl1b_b11_serial_candidate_search.rs) were committed before the independent path simulation. All five inputs `[-13,0,7,23,101]` × six arms were modeled for exactly **100 charged instruction opportunities**; results have the same executed-node trajectory across inputs but retain their actual input-valued service writes. No source commit has a confirmed passing native Rust CI.

**Key behavior:** In LESION10, three unsuccessful fresh-marker trials are followed by three **distinct CIL-sourced executable edge edits**, generated by reading the actor's *current* code and decrementing its next edge by one. A later trial produces the expected marker, the winning edge is retained, and further iterations use it. The observer did not directly inject which of the targets 9/8/7 to apply after starting the world. This is stronger as a **mechanism** than a single handcoded absolute repair target.

**Critical counterexample to naive “selection”:** candidate next9 executes the service write opcode under the wrong register state, so it writes to an unintended shared cell1, costing storage. Candidate next8 produces a valid output write but not the required fresh marker, so it is rejected. This is a *pre-engineered* selection objective and fixed code neighborhood, not an autonomous discovery of what constitutes maintenance or a positive life result. Mutation can have unwanted side effects even while the program remains executable.

Every arm finished 100 simulated attempts without trap. The Rust test additionally checks external/internal event provenance, exact CIL edge mutation ordering, side-effect cell1, finite storage and compute inventories. Native Rust CI must verify those assertions before experimental acceptance.

**Next scientific step:** Ask whether the **candidate-generation policy itself** can change and be evaluated using world-derived evidence, rather than staying a fixed decrement-by-one loop with a trusted marker. Compare against cost-matched scripted search, chance mutation and editing-disabled controls, with held-out lesions and evidence-spoofing. Repeating more of this same scripted policy does not demonstrate open-ended adaptation.
