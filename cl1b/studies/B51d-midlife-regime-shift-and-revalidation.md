# CL-1B B51d — retained-source behavior after a midlife hidden task-regime change

**Originally preregistered 2026-11-17 before native execution; B51d is now a NATIVE-VERIFIED NEGATIVE result (details appended below).** The source-pinned [B51c verified native result](../results/B51c-native-paid-multicandidate-feedback-retention-audit.md) is only a fixed-mode adaptation demonstration. The **same** 72-node researcher-authored B51c founder must be used unchanged for the first B51d causal falsifier. A redesign to add rechecking belongs to a later, separately identified **engineering intervention**, not the original B51d baseline.

## Question

Can an actor that has already used genuine paid functional feedback to retain a good executable program continue adapting when the environment **changes during its life**, without reset, task-specific code injection, privileged host repair, or external selection of a replacement process?

B51c retains source route node2→node30 and stops evaluating the output feedback bit. This may cause persistent functional errors after a hidden mode switch even if feedback remains available as ordinary world data. **H51d-no-revalidation**, prospective falsifier: in the unchanged native actor, post-retention mode changes should NOT trigger a new candidate search or source rerouting, and an externally written feedback cell after the transition should not help because the retained route does not pay a corresponding Read. A contrary native reentry into the search, paid source mutation or causal performance recovery falsifies this specific hypothesis. This is a scientific *negative control*, not a claim that no digital organism could ever re-adapt.

## Frozen experimental worlds

Use a single actual PID1 with the unchanged B51c founder, 1,300 initial paid CIL instructions, identical 16-cell/120-node/192-unit strict caps and no neutral compute refill. Repeat paired transitions from two early-solvable first regimes (to avoid exhausting compute before the second regime):

- **Transition A:** `f1(x)=x-2` to hidden `f2(x)=-x+3`.
- **Transition B:** `f1(x)=-x-3` to hidden `f2(x)=x+2`.

Every world first obtains its original B51c truthful two-probe source retention, then runs exactly **24 native heldout output11 Write events** on the frozen `[11,-7,0]` input cycle in mode f1. The experimenter changes the hidden task function only **after** those24 genuine writes; no task parameter, expected answer or stage marker enters an actor-readable cell. Continue for a further **24** genuine native output11 writes under f2. The third `RETURN` control switches to f1 again after the second 24 writes and records a final24; the other arms retain f2 for the third window. All worlds remain in the denominator if they stop early and may not be restarted or topped up.

Each transition has a prospective matched four-arm contrast:

1. **STATIONARY:** f1 never changes; same host observer schedule, feedback availability and paid execution opportunity.
2. **SHIFT_NO_FEEDBACK:** lab scores against f2 after the transition but does not update feedback cell20.
3. **SHIFT_WITH_FEEDBACK:** after each f2 output, lab writes a truthful 0/1 bit to ordinary cell20 as external-origin information; the native actor still must pay to observe it. This tests *availability versus actual use* of feedback, not guaranteed adaptivity.
4. **SHIFT_RETURN:** f1→f2→f1, without code reset, tests whether restored correctness is mere retained old source rather than new acquired knowledge.

Use one single source revision for all matched arms, exactly the same initial and realized compute opportunity where programs continue, and two deterministic entry-phase offsets (baseline and one charged no-op preamble) to expose timing artifacts. The preamble must not silently rewrite the founder's task logic; if a code shift changes absolute graph-node addresses, prefer an external charged competitor process (separately accounted), or document the inability to support the phase control. Avoid adding unnecessary mechanisms merely to force this offset.

## Evidence and acceptance

Record the exact hidden task mode at the **observer** level only, externally frozen input x, every native actor-origin service Write, true/wrong in each24-output window, source route state, charged instructions, remaining credits, storage, stopping and every external intervention with origin. Compare actual paid native events to an independently executed JavaScript CIL interpreter parsing the unchanged source. Require source SHA and complete, fail-closed same-run evidence.

**H51d-full transfer / cumulative recovery remains NOT MET** unless the *same actor* detects the change through paid native information, reopens its own hypothesis generation, changes retained source and achieves sustained correctness on unseen post-switch inputs, without researcher code rewrite, opportunity imbalance or host fix. If SHIFT_RETURN merely becomes correct when the original mode returns, score it as **previous source persistence**, not new adaptation. Include a strong static per-regime oracle separately, without giving that answer to the actual CIL actor.

The B51d original negative-control founder cannot logically see an unobserved input-function change when the output feedback channel is disconnected. This experiment is intended to pin down and quantify that barrier, not to inflate a foregone conclusion into life. If confirmed, a subsequent B52 may implement paid endogenous feedback rechecking and reopenable search, with the investigator origin of any new revalidation policy explicitly disclosed.
