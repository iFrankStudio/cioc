## Scientific objective

Existing CL-1B B52/B53 CIL actors use an **investigator-authored** feedback monitoring policy: every retained task output pays to read or verify specific external evidence, and a hardcoded failure branch reopens an **investigator-authored** affine candidate search. The actor genuinely executes paid source edits and changes task competency, but it has not invented or revised **how it decides to monitor, which evidence to trust, or when and how to search**. The 55/42 green integration suite measures correctness of prearranged mechanisms; it is not evidence of a self-originating adaptation strategy.

**B55 question:** Can one continuous finite-CIL individual generate, evaluate, retain and later revise **its own executable monitoring/search-control policy** rather than merely select a correct task program while a fixed guard executes forever?

Do not treat any rise in watchdog code size, native instruction count, or number of preauthored checks as progress toward B3 unless the causal origin of the **policy change** itself can be traced to the actor's paid computation and to consequential native data it encountered.

## Two explicit evidential tiers

### Tier 1 — paid monitor-choice engineering (lower bar; NOT B3)

Create multiple **independently instantiated, task-blind** monitoring-policy candidates with measurably different **per-output CIL compute and detection** costs: e.g. never check, check every output, check at variable intervals, and verify request/response serial before feedback use. A source-identical PID1 must actually **pay** to instantiate or modify its own executable control graph, perform at least two distinct prospective service trials, observe feedback and cost through available native CIL observations, and then patch the retained graph route. The objective signal and trial scheduling must be identified as authored laboratory mechanisms.

**Tier 1 ACCEPTED only if** a single continuous PID1 alters the monitor/source route through native paid `PatchNext` / `PatchConst` / `CloneNode` or equivalent ordinary instructions, and under exact equal compute and task exposure this causally improves a *preregistered utility function* relative to a seeded constant monitor and a host-blind/constant feedback selection control. Use a strong task-aware static monitor oracle separately. Selecting an investigator-seeded policy from a finite precompiled menu must remain labeled **authored selection**, never autonomous invention of the selection algorithm.

### Tier 2 — candidate evidence for genuinely self-revising metapolicy (higher bar; NOT automatically life)

A stronger experiment must not seed the exact useful monitor/control program as a preassembled correct candidate. Provide only generic allowed CIL primitives and a bounded capacity for generating new executable graph structure; require the **selection, monitoring and mutation-control routines themselves** to be reachable targets of actor-origin edits. Demonstrate a **new structural policy topology not present as an executable useful complete controller in the founder** that is first created through the actor's paid native instructions, then validated through actual service and retained under hidden task/environment changes. It must remain able to later abandon or revise the earlier policy after its costs or failure modes change.

For every change, maintain a provenance chain:
1. **before:** original graph, no prewired correct policy;
2. **actor cause:** native paid observations and the exact CIL instructions that create a new executable policy node/edge (not host graph replacement);
3. **functional consequence:** changed rate of paid monitoring work, errors, recovery delays, and survival under finite credits;
4. **later revision:** a second hidden environment regime forces reassessment of the first policy with no PID replacement, task-aware injection or compute refill;
5. **reproducibility:** all native events and graph diffs independently reexecuted from the same source revision.

If the actor's selection rule, reward function, mutation grammar, or restart trigger fully predetermines the newly useful monitor, report **Tier 1 engineering only** until a separate causal falsifier isolates a self-originated revision. Even Tier2 success would be only evidence for one B3 component, not a complete organism claim.

## Freeze the contrasts before executable B55 implementation

The first implementation should be a **source-identical 1-PID comparison** under strictly bounded compute and graph storage, without adding an `AutoAdapt`, `TruthFitness`, `TrustResponse` or other task-specific native opcode. Candidate CIL tools already exist: `Read`, `ReadNext`, `CloneNode`, `PatchNext`, `PatchConst`, `Branch`, `SenseComputePool` and `TryDrawCompute`; each reads or mutates only what its existing generic semantics permit.

Evaluate at least three prospectively frozen ecologies:

- **Stationary truthful task:** the program is already correct and unnecessary verification consumes native compute, reducing service throughput.
- **Unannounced task change under truthful current feedback:** checking intermittently may save compute but increases wrong outputs and recovery latency. Task family and hidden transitions must be frozen before candidate-policy tuning; inspect whether results survive heldout input phase and task return.
- **Stale/tampered feedback or neutral resource scarcity:** an unreliable success bit and credit competition can defeat naive always-check policies. An adversarial current-nonce lie is **not possible to detect from nonce alone**; never award correctness for assuming an oracle the actor cannot observe. If using environmental supply, charge draws and enforce resource conservation using existing CL-0 primitives, not an unlimited process credit top-up.

For each ecology, keep strong fixed-policy baselines at **identical source-independent compute opportunity**, report realized output writes and wrong writes, charged instructions per useful output, monitor checks per output, time to recovery measured in **native paid steps**, false alarms, source edit costs, storage and process-stop fraction. Do not discard terminated or unproductive worlds. Explicitly separate **actor-observable** task evidence from objective, hidden ground truth available only to laboratory evaluation.

Do not choose budget, graph caps, number of worlds or source graph after inspecting the candidate's hidden-environment outcomes: register these in a specific B55 executable protocol **before the first native test run**. This high-level research note is preregistration of the *scientific criteria*, not a claim that the detailed executable protocol is frozen.

## Independent and negative controls

- **No-monitor mutation:** disable native executable edits/graph cloning in a matched control and show whether task-utility improvement disappears.
- **Static seeded solutions:** if a preinformed task/monitor oracle beats the actor in service per CIL credit, disclose that limitation.
- **Blind/stale feedback:** random, constant-success and delayed bits must not be promoted to valid learner evidence.
- **No-op source edits:** a graph edit or read count alone does not constitute a new policy or a new functional capability.
- **Information aliasing:** if two worlds generate identical PID-visible histories yet have different ground truth, no actor-level policy can distinguish them without an additional causal signal; preserve this as a scientific impossibility, not a test failure.
- **Independent native instruction replay:** reconstruct every PID instruction, external event, source edit and credit/memory transition with a source-parsed separately authored CIL interpreter, exact GitHub source SHA, full/run-scoped CI labels, and fail-closed missing evidence.

## Stop/pivot rule

If the best result comes only from increasing a researcher-written watchdog or providing a larger static menu of precomputed monitor tactics, **do not inflate B3**. Instead return to the substrate/ecology design: what genuinely generic environmental affordances and resource pressures could make a previously unplanned self-generated monitoring policy useful? Assess whether a planned CL-1B experiment is answering that origin question or merely adding another prescribed behavior. The independent OCEE open-ended ecological research route is conceptually separate and should not be silently merged into this actor-lineage experiment.
