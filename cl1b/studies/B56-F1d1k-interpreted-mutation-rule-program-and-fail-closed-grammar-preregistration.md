# CL-1B B56-F1d1k — interpreted mutation-rule *program*, not merely a 1-bit preferred order (prospective)

**Status: prospective scientific protocol only. NO B56-F1d1k native experiment, result, CI pass or life claim.** This is a direct follow-up to [the source-pinned completed F1d1j study](../results/B56-F1d1j-native-original-PID-paid-mutable-mutation-rule-and-negative-transfer-audit.md), which verified 60 original PID1 worlds, 47,705 independently reexecuted paid CIL steps, 14 actor-paid writes to preference cell63 but only **5 effective value changes**, real positive repeated-task savings, harmful rule transfer and targeted feedback deception.

## Why another rule-switch experiment is not progress

F1d1j's mutation preferences R0=C-first and R1=B-first were **both preauthored**. PID1 selected their **1-bit index** with feedback, but the shape and semantics of the entire rule remained fixed. For B56-F1d1k, merely introducing R2/R3 as more prewritten, branch-selected complete candidate policies, or adding artificial generations/reproduction, is forbidden as positive evidence.

**Precise prospective hypothesis:** Can one original PID1 (strict unchanged CL0 world) **pay to assemble and edit an interpreted mutation-rule PROGRAM of at least two separately addressed meta-instruction slots**, execute that rule program to produce its NEXT task-program data-slot Writes, evaluate on real two-probe candidate services, and retain or rollback the rule program after a task/regime shift? A successful test establishes **composition/editing of a rule program from a finite researcher-authored meta-instruction alphabet**, *NOT* de-novo invention of primitive semantics or open-ended evolution.

The critical novelty of the test relative to F1d1j is that native PID1 source may contain **a generic rule interpreter and a bounded set of atomic meta-operators**, but **must not contain a separate full hardwired branch for each of the complete target rule programs**. Each new tested rule must be represented by independently mutable **multiple data-program cells** and dispatched through *several actual meta-instruction fetches*, with actor-paid storage and fetch costs. A static one-bit rule index with an if/else selecting B vs C is a **FAIL**, even if it predicts heldout perfectly.

## Meta-rule semantics and scientific validation gates

Prospective minimal meta alphabet (these are **human-authored primitives**):
- `PUSH_CANDIDATE(mode)` or `SET_MODE(mode)`: choose one authored task-bytecode candidate as a **data value**, not a privileged host-installed full program.
- `ADVANCE_OR_SWAP`: alter which candidate to try next using a stored pointer/ordering.
- `EMIT_MUTATION`: perform real native PID1-paid writes of at least two task-program bytecode slots, using the values produced by the meta-operator sequence.
- `STOP_OR_RETURN`: stop the meta interpreter and hand control to the task-program evaluator.

The eventual exact experiment may choose a smaller instruction grammar, but **must preregister an exact meta-ISA, source graph, task ISA, valid program-length bound, all cost accounting, all branch edges and all physical memory addresses BEFORE native implementation**. The researcher may provide the initial meta-alphabet and initial rule seed, but **may not inject the eventual winning rule program or pick its descriptor after seeing the hidden task**.

Hard requirements:
1. **Two-level execution trace:** each rule edit is a charged PID1 Write into its own meta-bytecode memory, each meta instruction is fetched from its data address by PID1-paid native CIL Read, and the **next actual task-program slot Writes depend on these fetched meta-instructions**. Store at least one actor-written intermediate meta-state checkpoint. Native code graph never changes.
2. **Multiple structural alternatives:** demonstrate ≥3 **different effective, multi-instruction rule programs**, at least one created by combining rule parts and not by selecting a complete prebuilt branch. Distinguish 1:1 semantic equivalence or redundant edits from **effective rule-behavior changes** (F1d1j had 14 paid writes but only 5 value changes).
3. **Causal ablations:** source-identical frozen-meta-rule, charged meta-write suppression, corrupted feedback, literal ABSENT feedback and an initially privileged optimal-rule baseline. For same task/probes, changing only prior ordinary feedback must alter **the following meta-program's paid instruction-slot sequence**, and later, under *identical new truth feedback*, the next actual task-program edits. Preserve negative transfer when a learned rule becomes harmful on a regime shift.
4. **No hidden oracle:** host writes only authorized input/feedback/control cells. Truth is supplied by an externally held task oracle and is a *controllable signal*, not PID1-trusted ground truth; a maliciously changed bit remains a real invalid environmental case.
5. **Finite original source accounting:** CIL `World::with_strict_capacity(16,180,300)`, PID1 only, ≤180 original native source nodes, ≤16 simultaneous live data cells, ≤300 occupied units, finite predeclared credits, no pool replenishment, no privileged self-credits sensor. Program output and rule updates both spend original PID1 instructions. **Do not reuse external edit-permission gate as actor-editable meta memory.**
6. **Rule/program provenance:** editor, interpreted rule, task-code slot writes, output, feedback, score and validation must be linked by exact source-native instruction traces, not inferred from a precomputed task label or end-state alias. A second independent CIL interpreter must reexecute **all** original native instructions and host interventions, aborting at first divergence.
7. **Negative cases are first-class:** invalid meta-bytecode must be rejected or halt at a documented source-visible validation branch, with charged recovery; a meta-rule that cannot solve an unseen task must produce an **explicit failure**, not an invented success; missing feedback Read20=0 does not mean absence is recognized.
8. **Cost normalization:** compare correctly solved heldout services and rule-update attempts per **actual paid CIL instruction** (external audit), and separately the actor's *own paid cost surrogate*. Never mislabel the actor's surrogate as direct sensing of its exact remaining credits.

## Resource feasibility — expected bottleneck

F1d1j used **177/180 native CIL source nodes**, all **16 address keys**, peak storage194/300, and a fixed one-register-width rule descriptor. The new experiment **cannot simply append a rule interpreter**: only three native source nodes remain and no additional shared data address exists. A credible F1d1k implementation must **refactor/compress the task interpreter and evaluation controller, or reuse keys with source-paid Delete/reallocation or address-role phases**, within the UNCHANGED substrate; it may have a new researcher-written original founder for this experiment, but must clearly flag that this is **not spontaneous code evolution of the F1d1j/F1c founder**.

Therefore, before any native F1d1k source, first commit:
- A machine-readable *separate task-ISA and meta-ISA* spec, executable source-node and register/branch allocation, **live-cell lifetime and peak occupancy audit** with read-after-write/alias checks.
- A bounded grammar and full heldout/feedback matrix including crossed task-shift directions, purposeful misleading rule-learning signals, frozen-meta-program and code-edit suppression arms.
- The strongest reachable **hard-negative architecture** if 180-node or 16-cell exact feasibility fails: preserve this failure as a resource-bounded limitation, do not patch kernel semantics to claim success.

**Acceptance boundary:** even full passage proves *within-person charged self-editing of a data-program that controls program mutation*, with researcher-authored primitive meta-operations. It does **not** prove unbounded open-ended algorithm invention, B53 authentication, continuous original F1c founder identity, strict N56-A/B/C, B3/B4 or cyberlife.
