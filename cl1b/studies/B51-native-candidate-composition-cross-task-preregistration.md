# CL-1B B51 — native candidate *composition* and cross-task transfer

**Prospective design checkpoint, 2026-11-17. NOT IMPLEMENTED OR NATIVE-VERIFIED.** This study must not inherit B50's negative outcome as its own result. The latest full native baseline is [B50, 49/49 Rust +36/36 observers](../results/B50-native-feedback-vs-forced-construction-audit.md); B3/B4 and cyberlife remain NOT MET.

## Motivation and obstacle

B50 falsified the necessity of task feedback for a program whose *winning candidate Write instruction* was already authored in a cloneable form. Merely forcing the founder to execute that ready-made repair outperformed real-feedback-gated selection under exact equal compute. **Do not make B51 a bigger B42 clone with more chosen constants, more hand-built success routes, or an externally selected best-of-N.**

The next indispensable mechanical capability is that one continuous, finite-budget native CIL actor can build **at least two distinct executable candidate programs by combining ordinary graph operations**, test them through *paid and temporally attributable* information, reject failures, retain the better local change and then confront new input/task conditions with the **same founder and candidate-generation policy**. A researcher-authored grammar or search controller still prevents full B3 endogenous-policy acceptance; it is a calibration step, not a life breakthrough.

## Frozen design constraints

1. **One CIL organization, no reseeding.** No new process IDs needed; actor writes and later executes mutated code nodes during one continuous timeline. Explicit finite storage/compute budgets, occupied units, attempted instruction charges, and input-output provenance. If neutral compute replenishment is used, it must satisfy the B18/B19 audit (environment-level, identity-neutral flux acquired through charged actor operations); host-directed credits are disallowed as native resource acquisition.
2. **Operator primitives, not an already-correct repair.** Provide a minimal generic founder library containing normal `Read`, `Write`, `Const`, `Add`, `Sub`, `Branch`, `CloneNode`, `PatchNext`/`PatchConst` and ordinary stored cells. No preassembled correct task-specific Write route, correct parameter, solution table, hidden expected output, or host `OPTIMIZE` instruction. The actor must pay for constructing *and executing* different arithmetic/control-flow graphs. A successful candidate must have a verifiable actor-origin graph identity/edge set distinct from other trials and absent as a complete solution graph at initialization.
3. **Tasks where one-copy-fits-all fails.** Use a small, frozen, externally defined black-box family `f(x)=s*x+k`, with `s ∈ {+1,-1}`, `k ∈ {-3,-2,+2,+3}` (eight modes), and input values including positive, negative and zero. The family is deliberately simple enough for the available arithmetic primitives but requires at least two **structurally different** executable forms (e.g. `x+k` and `k-x`). Freeze full train/validation/holdout partitions, ordering, and phase shifts before implementation. Do not expose `s`, `k` or the expected output as read-accessible world data.
4. **External correctness is an explicitly labeled laboratory training signal, not endogenous motivation.** The world environment can accept a native output submission on shared cell11 and *after* that native Write expose an ordinary feedback cell containing only a bounded success/failure bit, marked `Origin::External`; the actor must pay `Read` for it. The environment must not silently set actor executable code, actor credits, or the correct answer. The evaluator's correctness logic and task are external and thus **never** evidence of native spontaneous goal formation. On evaluation holdouts, feedback stays absent or unchanged, and no oracle labels leak to the actor.
5. **Anti-aliasing and causality.** Use at least two distinct nonzero training probes per candidate before retention; include adversarial x=0 and mirrored task pairs to detect observational equivalence. Score with the input value captured at the external task boundary, not actor-modifiable cell7 alone. Count false accepts, false rejects, and task/feedback races; include B44/B46-inspired same-value or stale-feedback controls when the mechanism allows them.
6. **Strong controls and compute fairness.** Compare the *same founder graph* with (a) native feedback suppression at equal charged opportunities, (b) unconditional same-grammar candidate retention, (c) self-edit disabled, (d) a compact immutable copier, and (e) a compact per-task static oracle as upper bound. Report **actual paid steps**, stopped worlds, storage, candidate count, distinct native code graphs, selected source hashes, correct/wrong heldout writes, and restored functionality. Early-stopped worlds stay in the denominator; no favorable phase filtering.
7. **Out-of-sample gate.** For each task mode, train on one frozen input set, validate against a second, then evaluate unseen x without feedback. Finally present at least two *previously unseen modes* to the **unchanged** native founder/policy, allowing a new limited training phase but no researcher reseeding, and recheck that previously acquired competence persists where applicable. Native candidate changes alone are not a learning result if heldout accuracy fails.
8. **Independent audit.** Native Rust must record source-pinned, exhaustive event/provenance/energy/graph-change evidence sufficient for a separate CIL interpreter to reproduce actual candidate construction and scoring; if a full 10k+ step trace is too costly, preregister exact event sampling *before* CI, not after selecting successful cases. Fail closed on missing native trace, outcome divergence, or changed task-set.

## Hypotheses and permitted inference

- **H51 engineering feasibility:** an actor must truly construct and execute >=2 graph-distinct candidate programs through native paid graph operations, with no fully composed correct candidate at seed; source-pinned native and independent execution records agree. If no distinct executable construction occurs, stop and report a negative substrate result.
- **H51b selection utility:** under equal realized compute opportunity and preregistered holdouts, native feedback-driven retention must outperform **both** suppression and unconditional construction on precommitted heldout correctness without increasing wrong outputs. The compact copier and per-task oracles are independently reported, not silently excluded. Failure rejects H51b.
- **H51c transfer:** exactly the *same founder and search mechanism*, without code or hyperparameter redesign by the researcher, must adapt to previously withheld task modes and retain benefit on unseen inputs; knowledge gained in one task cannot be counted if a reset or externally selected replacement code supplied the new variant. Failure rejects H51c.

Even joint H51/H51b/H51c engineering success would demonstrate only a **researcher-designed generic synthesis/selection mechanism** in a finite task ecology. Stronger B3 demands endogenous origin/revision of the mutation/selection strategy and durable benefits across broader unforeseen conditions. B4 additionally requires endogenous organization/maintenance under neutral resource flux. No unbounded autonomous execution, outside software/network access, or production privileges are authorized here.

## Implementation sequence (each with a stop condition)

- **B51a:** freeze the deterministic native task/feedback event interface and a source-audited no-label-leak control. Abort if an actor can read the answer or bypass charge accounting.
- **B51b:** native CIL two-graph construction, exact storage/energy/provenance controls and zero-opcode-special-case check. Abort if only a preexisting correct node is selected or an external hook performs assembly.
- **B51c:** paid multi-probe selection + independent actual CIL replay. Abort if disabled/forced source has unmatched exposure or if a reward-bit/phase alias controls the reported gain.
- **B51d:** prospective holdout/transfer, matched stronger baselines, and full source-pinned CI. Record both accepting and rejecting outcomes without changing the hypotheses.
