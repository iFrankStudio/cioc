# CL1B-G2-PC28-NATIVE-C1 · 原生付费源码参数修改效应的同源因果实验（预注册）

**2026-11-22 UTC；先冻结、后执行原生 Rust。** 依据：G2 原生证据 [#44917352841](https://github.com/iFrankStudio/cioc/actions/runs/44917352841)（103/103 原生、63/63 观察器、184 世界、283918 CIL）；近期的 [PC28 源码级探索](../results/CL1B-G2-PC28-exploratory-counterfactual-statistical-evidence-audit.md) 只得到已公开任务 +156 指令、六组非零且方向混合，**绝非原生因果效应**。

## 核心可证伪问题

在 G2 的**完全相同、180 节点、研究者最初编写的** CIL 中，只去除 PID1 在实际 PC28 执行的 `PatchConst` 对未来 PC173 `Const.value` 的代码效果（**仍真实收费、仍运行全部原生指令和其它源码修改**），相比不抑制的原生世界，24 个真实任务阶段完成后的全生命周期 CIL 成本有何因果差异？

这只测**预写的个体付费策略参数自修改**的因果效应，不测自主发明、开放式演化、跨世界记忆或证据认证。任何观察到的收益都不可夸大为 B3/B4。

## 原始 G2 源码、四种独立实验臂

原始个体代码从已经 [源冻结的 G2](CL1B-REFILL-RULE-G2-frozen-180-node-self-modifying-184-world-v1.json) 按字节加载；不许更改 `G2_changed_allow` 和 `G2_never` 的任何节点，严格 16 数据槽 / 180 源代码槽 / 300 总存储 / 6000 私有 CIL 额度、单 PID1、24 真实阶段与原生 PC3 Write11 → 外部真实反馈 cell20 → 付费 Read20。

每组完整24目标固定四个独立原生世界，顺序一致：
1. **on**：G2_changed_allow，原生无干预，PC28 正常付费修改 PC173 的 Const。
2. **off**：G2_changed_allow，完全同一 CIL 初始源码，研究者开启**精确 PC-local** 效果抑制 `(pid=1,pc=28,patched_const_node=173)`；正常 PC28 PatchConst 的全部寄存器、合法边、目标是否 Const 的原生有效性验证、计算收费必须保留，只是不能修改 PC173 的实际字节。其它 PatchConst/PatchNext/Write 一律原生正常执行，不能暴露 host gate 给 PID1。
3. **placebo**：与 on 同源，配置 `(pid=1,pc=180,patched_const_node=173)` 的不可达假干预；不得增加任何原生合法节点；on/placebo 的原生逐条 trace 和最终结果必须在标签归一化后完全相同。
4. **never**：独立 G2_never 冻结源码（**不同源码**），作为强固定计算基线，只用于决策是否有净成本竞争力，不得当作同源 PC28 因果对照。

**内核变化仅可为默认关闭、研究者可配置的精确 PatchConst 效果屏蔽。** 必须对错误 opcode/PC/target 不一致失败关闭；不得修改原始默认内核执行物理或给 actor 新指令。原本收费一次的 `PC28` 在 off 中仍收费一次，包括后续可能出现更多/更少的 PC28 执行，不用对应原轨迹总步数强制相等。记录 `EventKind::NativeCodeEditSuppressed{opcode_tag:9}` 或等价的已存在原生事件溯源。

## 先冻结新任务与混合权重

**45 个真正新源冻结的 24 目标序列**：5 个预定义环境族 × start0,1,2 × stride0,1,2，每个族9例；xorshift32 初始化种子 `0xC11B6C35`，在 JSON 冻结清单中保存每一个真正用于实验的完整 goals。新的实际序列必须与 R1 的189组、G1 的45组、G2 的45组均**逐向量不重合**，重复时冻源生成阶段即失败，绝不在得知原生结果后替换。五族：慢持久两次变化、短脉冲快回退、延迟方向反转、前后重置与稀疏随机冲击、含终端低频扰动的平稳族。每组四真反馈共180世界；加4个假反馈控制（inverted/forced0 × on/off）= **184 个原生世界**。五族各9组、全权重预先冻结；不对曾出现正方向的旧 rapid-reversal 世界做选择性加权。

## 测量、独立验证、否证门槛

首先断言真反馈的各世界实际 **24/24** 完成真实隐藏目标，发生提前停机、预算耗尽或假成功不能列为省指令的胜利。主因果指标逐组 `delta = total_private_paid_CIL(off) - total_private_paid_CIL(on)`。正数＝保留自修改省资源，负数＝自修改损失资源。完整报告45例 delta、正负平、五族和整体等权累计费用；**无预设效果下界或“必须正收益”的软式通过条件**，不做事后环境挑选；单列 no-exposure / PC28 attempted / actual changed PC173 / later truly read changed theta。数据支持时描述局部因果关系，不将探索性旧结果作联合 confirmatory 样本。

一致性要求：
- on 与 placebo 的 **每条原生 CIL+反馈事件精确相同**；off 首个真实抑制 PC28 之前与 on 的原生 CIL 原始事件一致（出现效果干预的步开始 provenance 可不同），之后允许世界分叉。
- 在 off 发生真正命中时，本来待写入的寄存器值仍为0..2，PC173 原生 Const 不变，且原生事件溯源为“被抑制”，PC28 仍付费，外部真实目标从不影响此逻辑。
- 精确读取逐行原始 native JSONL；再由**独立 Python CIL 解释器**从冻结原始源码推导所有真实 CIL 寄存器、PC、PC173 修改状态、源码边、存储、额度和原生反馈；不同源 never 也必须重放。
- 记录被抑制的 native PC28 次数、首次真实暴露、非暴露完全同价、placebo 原生一致性、真实完成数、总成本和假反馈的错误成功声明；禁止遗漏测试目标或用 source-level 预测替代 native。
- 任何结果均须原样保留；若净效应接近0或异号，明确标注“不支持普遍收益”；即使正也不能自动认定自动进化或生命诞生。若内核新选项破坏既有 CL1B/CL0 原生回归则实验失败。
