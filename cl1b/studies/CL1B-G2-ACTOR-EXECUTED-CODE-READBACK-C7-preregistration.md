# CL1B-G2-ACTOR-EXECUTED-CODE-READBACK-C7 · 个体付费从真实执行结果读回源码参数（事前冻结）

**2026-11-22 UTC；在任何C7新任务原生Rust结果之前提交。**

## 问题和历史证据边界

已核验C6：PID1自行有偿记录其拟安装的`PC173 Const.value`进cell40，45任务中13次相同参数跳过修改只省52条死指令，整体仍比始终不修改多付983。宿主严格抑制27次真实收费PC28的实际源码效果后，**18次后续门控把“我尝试写入的参数”误当成真实参数**。这证伪了仅凭写入意图的“自代码镜像”认证。CL-0没有可直接读活动源码`Const.value`的`ReadConst`指令；已有B04用`ReadNext`取可执行边，但`ReadNext`不能直接取Const的数值。本次试验区分**写入意图**与**亲自执行代码产生的标量观测**，不假装新增一个内核源值传感器。

**精确能力假说：** 可以把`PC173`真实执行时写入主体`r2`的数值，通过PID1自己付费执行的后继`Write41`保存；在下次自修改gate前读回该被真实执行的值，而非之前请求写入的值。即使研究者仅抑制`PC28 PatchConst`对物理`PC173.value`的效果，下一次`PC173`真实执行时仍应读回其物理实际值，不应被先前写入意图污染。这是**执行时的有费局部自观测**，不代表密码学认证、任意源码读权限或能识别内核恶意执行。

## 精确180节点源码修改（C6原始源码上的五处）

所有世界维持原生单PID1、**16数据单元、180源码节点、300总占用、6000私有收费CIL、48阶段隐藏真目标**；不给主体未来任务、不增加第二进程/池、不引入`ReadConst`或免收费主机回传真实源码。基于已验证C6完整源码只动五节点：

1. `PC173 Const dst=2 value=当前源码值 next:174→24`，所以**它必须先真实执行，产生真实寄存器r2**，才进入证据记录；
2. `PC24 Const dst=1 value=41 next=52`，`PC52 Write address=1 value=2 next=174`，两条都由PID1原生付费执行，把最近一次真实执行的源码θ放入cell41，再回到原PC174任务计算；
3. `PC28 PatchConst node=r1 value=r3 next:24→125`，**不会在执行修改请求后提前写入意图当成成功认证**；
4. `PC79 Const dst=2 value:40→41`，保留已有付费`PC120 Read cell[r2] → PC57 Sub(r3−readback) → PC67 Branch`，用最近一次真实执行代码而得的`cell41`决定是否付费进入PC27→PC28。

无其它节点、边、预算变化。原本未创建cell41时`Read`返回0，与PC173原初值0一致。该方案的**信息新鲜度只到最近一次执行PC173**：如果PC28修改之后从未执行PC173，cell41可能滞后；因此必须记录每次gate之前最近的真实PC173/PC52事件，不能假设只要声明有镜像就已经验证最新代码。在已有C6实际执行路径的源码级可行性试算中，PC173通常先于下一次门控，**旧45个C6任务只用于工程预检**，不计入本轮45新任务或新样本收益。

## 冻结世界矩阵和强基线

**45个新的未在C5、C6矩阵出现过的完整48阶段隐藏目标**，五族各起点a0..2×步长d0..2共9例。固定Xorshift32主种子`0xC11B7A77`，每个例子按族/a/d顺序生成子种子，全部目标`(a+d*t+offset(t))%3`，offset定义：
- `middle_double_flip`：t<12→0，12..24→2，25..38→1，39..47→0；
- `late_small_shocks`：33..37→2，43..45→1，其它0；
- `twelve_block_rollover`：floor(t/8)%3；
- `multi_impulse_shelves`：t%17属于{1,2,3,9}时2，否则0；
- `seeded_novel_drift`：每例从自身新子种子开始每阶段推进xorshift32流，`random%7==0`时offset=(offset+1)%3，否则`random%19==0`时offset=(offset+2)%3，其余不变。

每条冻结目标并行六个真实单PID1世界：
- `G2_readback_attest`：C7真正自行付费的源码执行后读回参数和有条件修改。
- `G2_readback_always`：**只改PC67的zero出口为27**，仍照付PC173→Write41和Read41比较成本，但每次门控均真实进入PC28。
- `G2_readback_abstain`：**只改PC67的nonzero出口为125**，付同样的证据监控成本但永不PC28。
- `G2_readback_pc28_suppressed`：与readback初始源码字节完全相同，仅研究者严格抑制原生PC28对PC173的实际源码修改效果（**指令照常收费**）；下次PC173被真实执行时应写下真实而非意图值。
- `G2_readback_placebo180`：与readback初始源码相同，仅抑制不可达PC180，全部原生CIL+反馈逐行必须与readback相同。
- `G2_intent_mirror_C6`：已验证C6代码、**不同初始源码**，仅作工程效果对照；不能把成本差归为readback传感器纯因果效应。

45×6=270真实反馈世界，外加`inverted`和`forced0`×readback/always四个假反馈对照，总计**274原生世界**。真假反馈都只能在原生`Write11`之后送入cell20；真正隐藏目标不暴露给主体；假反馈不能当成真实目标完成。
