# CL1B-POLICY-P4F5 — preregistered actor-paid bounded re-editing

**Frozen before any original-native P4F5 Rust execution.** Inherits the exact P4F4 native baseline ([full SUCCESS #44852635243](https://github.com/iFrankStudio/cioc/actions/runs/44852635243)).

This is a **falsifiable one-edit budget** experiment, not an assertion that a fixed quota is optimal. P4F4 repeatedly pays to rewrite executable stride PC46 after failed task feedback, sometimes for 20 online edits per 24-stage episode. P4F5 adds a paid data-cell38 meter. Original PID1 pays to Read38 at the original failure path and only attaches expensive success monitor when it has performed fewer than **one online PatchConst PC122**. At the first genuine actor-paid online PatchConst, CIL PC147..152 pays to set the meter to1. Thereafter PID1 skips further *online success delta* rearming but may still use earlier F1 fallback `PatchConst` logic. **153 original CIL nodes**, 16/180/300 world limits, 6000 private credits; no host mutation of CIL source.

**Frozen protocol:** 108 previously observed P4F4 goal sequences plus **36 genuinely new**: one permanent midstream stride drift, two separated permanent shifts, periodic isolated spikes, and a quiet prefix followed by dense two-stage spikes. Each case is 24 tasks, three starting goals × three initial strides per regime, with **three distinct original Rust PID1 worlds per sequence**: F5-on, F5 same-initial-source PatchNext suppressed (but all instruction charges kept), and F4-on. Add two adversarial false-feedback controls = **434 original native worlds**. The manifest contains full vectors and immutable loaded CIL source.

**Negative outcomes required:** A capped online editor can save computation on frequent nonpersistent shock regimes yet fail to adapt to a second long-lasting shift. Record net *charged* CIL instructions, actual task probes, all native completion/truth, paid edits PC45/88/102/122, paid meter cell38, original source control edits and independent replay. A cross-source F4/F5 net difference is **not** the source-identical edit-bundle effect and cannot establish that the meter alone causes an outcome. We must not label one hard-coded edit budget as autonomous discovery of compute-optimal policy.
