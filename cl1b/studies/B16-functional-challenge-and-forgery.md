# CL-1B / B16 — CIL-originated nonzero challenge and actual payload readback

**Prospective registration: 2026-11-15, before B16 integration test and independent B16 outcome computation.** This is a **researcher-designed diagnostic protocol**, not self-originated goals, true autonomous learning or a completed CL-1B stage. B12/B13 demonstrated that a fresh internal "success marker" can exist without the required functional output. B16 tests a **more causally direct observation channel**, while explicitly attacking it.

## Hypothesis and hard limitation

Instead of checking a separate status marker, a continuing CIL individual creates a **known nonzero challenge value (17)**, writes it to an ordinary source cell, deletes the stale output cell and exercises its *real payload-producing opcode*. It then reads the actual output cell and compares the value with 17. A missing read of 0 cannot be mistaken for 17 even when the user's original input equals zero.

The challenge constant17, output criterion, repair address and one-step edge decrement are **all written by the researcher**. They are **not** a discovered life goal or external reward. A malicious writer can still forge the payload after reset, and certain code lesions can bypass the actual checking path.

## Frozen 30-world fault matrix

Five source-input labels × six arms. All execute **120 charged native CIL attempts**, with one process, finite credits, no replenishment. All initial host interventions are explicit `Origin::External`. The only after-start intervention is in the specifically labeled timed-forgery arm.

1. **INTACT:** source PC10.next11, no other intervention. Correct nonzero PC11 challenge and PC31 ordinary service writes; no repair.
2. **SERVICE_SKIP:** external `PatchEdge(node10,next12)` skips PC11 but retains the readback check. First read sees missing output0 (even when input0); CIL proposes native edge restoration 10:12→11. Later actual challenge and ordinary service writes return.
3. **SERVICE_SKIP_STALE_PRESEED:** host pre-seeds cell11=17 before execution, then same PC10.next12 fault. CIL's PC7 Delete must clear the stale output; result should be the same as SERVICE_SKIP.
4. **SERVICE_SKIP_PATCH_DISABLED:** same code lesion, with `with_native_patchnext_disabled()` world law. CIL attempts the edge change and pays its cost, but cannot restore PC11 payload production. **Important:** PC31 may still provide ordinary service even though its *challenge path* is damaged; record that rather than reporting total service=0.
5. **CHECKER_BYPASS:** external `PatchEdge(node10,next13)` skips PC11 **and** PC12 which loads the output-address register. PC13 now reads cell7=17 instead of cell11; comparison succeeds while **no actual PC11 challenge write occurred**. Expected false acceptance with no native repair, even though the challenge was generated by the actor. This is the vital source-corruption negative control.
6. **TIMED_FORGED_RESPONSE:** node10.next12 lesion; after exactly12 attempted native instructions, just after PC12 and before PC13, researcher externally writes cell11=17. The first check is fooled without a PC11 write. The next trial deletes the forged output and should detect the real fault, permitting repair. Count this injection as external and record the first false accept.

All arms keep the original source value in CIL cell15 and restore cell7 during each full cycle. No host code restore after initial lesion.

## Registered endpoints

- Distinguish genuine challenge payload writes at PC11, ordinary service writes at PC31, CIL output deletion at PC7, and internally sourced native `ExecutableEdgePatched(node10,12→11)`. Merely reading17 from a cell does **not** count as payload work.
- SERVICE_SKIP and STALE_PRESEED must restore from native evidence and produce at least one later genuine PC11 write. PATCH_DISABLED must leave next12 and produce no PC11 writes, though PC31 ordinary writes remain possible.
- CHECKER_BYPASS must have zero PC11 writes, at least one false-acceptance observation at PC13, no effective repair, and persist next13. This explicitly falsifies the assumption that a direct payload-readback channel is invariant to **arbitrary control-flow edits**.
- TIMED_FORGED_RESPONSE must have no PC11 write before first forged read, at least one subsequent native restoration and actual PC11 write, and correct external attribution of forgery.
- Every world has exactly 120 charged opportunities and ending local/inventory compute120, unless trapped (which must be reported and fail the full-window expectation). No trap, birth or unreported host repair.
- A valid zero-valued original input must be restored and represented by a genuine PC31 Write; the challenge remains17 to avoid the missing0 alias. The test must not mistake a host preseed or injected write for CIL-generated service.

## Scientific interpretation

A known nonzero challenge plus CIL-managed deletion provides better evidence of the **actual payload write** than B10's independent success marker under the specifically frozen SERVICE_SKIP lesion. But it still fails against checker-path corruption and timed active forgery. This is an epistemic boundary of mutable software, **not** a completed independent functional oracle. The next true adaptive gate requires the actor to vary its own probe and choose among policy hypotheses on held-out faults, with resource and source provenance, without a hardcoded trusted verifier.
