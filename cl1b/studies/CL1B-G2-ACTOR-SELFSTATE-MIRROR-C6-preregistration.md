# CL1B-G2-ACTOR-SELFSTATE-MIRROR-C6 · 个体付费维护自身参数镜像、拒绝重复自修改（事前冻结）

**2026-11-22 UTC；任何C6原生运行结果前冻结。** 直接继承C5原生814世界发现：研究者编写的C4 `r3!=0`门控用的是最近成功输出标签，不是修改净收益证据；有些环境修改真实有利，另一些环境成本更高。本次不继续任意调整标签阈值，而是验证**更基础的主体可取得信息**：不依赖内核赐予的源码读权限，PID1能否自己付费记录上次修改安装的真实参数，并在下次拟修改相同值时有偿跳过冗余源码写入？

## 实体、源码和证据分类

原始CL0保持**单PID1、16数据单元、180个CIL源码、300总占用、6000私有有偿指令、48真实隐藏任务阶段**。没有任何增加的CIL操作码、免费补充算力、研究者在运行时选编辑、研究者传入未来goal、其它PID或预知赢家。

C4初始180节点**所有槽均被占用，且历史世界中都执行过**，但存在五个可证明**无条件等价跳转**（只有一个静态源前驱，且原生PatchNext只动态修改12/34/133，未动态引入五个旧空操作作为新目标）：
- PC24旧`Branch ->0`，将PC23原`next24`直接改至0；
- PC52旧`Branch ->22`，将PC51原`next52`直接改至22；
- PC57旧`Branch ->22`，将PC56原`next57`直接改至22；
- PC79旧`Branch ->44`，将PC77原`nonzero79`直接改至44；
- PC120旧`Branch ->121`，将PC118原`nonzero120`直接改至121。

这些重连只省掉无差别转移的原生费，不代表“没有执行过的免费槽”。**所有C6研究臂共享这个源码骨架**，不能把它省下的费用当成镜像策略本身的收益，也不将C6与历史C4不同源程序的费用差当成因果。

复用释放出的五槽，原生支付如下新流程：

```text
PC26 PatchNext(...).next -> PC79
PC79 Const r2 = 40
PC120 Read r0 = cell[40]  // 未创建时原生Read返回0；初始PC173.value=0
PC57 Sub r0 = r3 - r0
PC67 Branch test r0: nonzero -> PC27, zero -> PC125
  修改分支: PC27 Const r1=173 -> PC28 PatchConst PC173=r3
             -> PC24 Const r2=40 -> PC52 Write cell40=r3 -> PC125
  放弃分支: -> PC125
```

`cell40`是**PID1自身实际付费写入的可持久数据单元**，在任意未被研究者干预的镜像源中，其应在每次原生门控时等于**目前已生效的 PC173 Const.value**（没有原生ReadCode API或外部源码值传递）。每次读镜像、比较、选择、写镜像都从主体私有预算扣除实际CIL费。镜像分支测试的是**是否已安装相同值**，不是“修改能否提升未来算力效率”。

## 全冻结策略对照

每个新任务独立运行六臂：
1. `G2_mirror`：上面的主体内源状态镜像比较，若拟安装的`r3`与镜像不同则有偿执行真实PC28及Write40，否则直接跳过。
2. `G2_mirror_always`：**除PC67的零出口=27外完全相同**，照样付PC79/120/57/67判断费，始终PC28+Write40。
3. `G2_mirror_abstain`：**除PC67非零出口=125外完全相同**，照样付判断费，从不PC28+Write40；镜像初始0无变化。
4. `G2_mirror_pc28_suppressed`：与mirror完全相同初始CIL；仅研究者原生屏蔽真付费PC28修改PC173效果，但**PID1仍真实付费Write40**。因此本臂故意构成**镜像遭污染的对照**，不可将相对于mirror的总成本差解释成纯净的PC28源码编辑因果效应。
5. `G2_mirror_placebo180`：与mirror完全同源，研究者仅屏蔽不可达PC180，要求全部原生收费CIL/反馈逐行与mirror完全一致。
6. `G2_legacy_label_gate`：C4原始输出标签门控的**不同源码**，只作工程参照，不能算mirror纯因果消融。

在正常mirror、always、abstain和placebo臂，每次到达PC67前必须按原生读取的真实值断言`cell40==当前PC173 Const.value`，并保证PC67付费路由符合源码。mirror在PC67若相同必走PC125，若不同必走PC27；至少两种路由均应真实出现。被压制修改的污染控制不使用此相等断言，必须记录每个`shadow!=trueθ`事件；即使没有发生也要诚实记为阴性。

## 新任务冻结

创建**45条此前未使用的48阶段完整任务目标向量**，五个固定族×起始值0/1/2×步长0/1/2，主Xorshift32种子`0xC11B6C46`，按此固定顺序每例先更新种子，均不在实验后选择有利样本。每阶段真值`(start+stride*t+offset(t))%3`，五种offset：
- `two_regime_offsets`: t<14为0，14..28为1，29..41为0，42..47为2。
- `long_stable_runs`: t<11为0，11..34为2，35..43为1，44..47为0。
- `alternating_bursts`: t%13∈{2,3,4,8,9}时2，否则0。
- `six_stage_reversal_motif`: 按floor(t/6)%4循环取{0,2,1,0}。
- `seeded_sparse_nonstationary`: 每例以本例已冻结的子种子再按每阶段Xorshift32抽值；值%7==0时offset加1 mod3，否则值%29==0时加2 mod3，其它保持先前offset，初始0。

共45×6=270真实反馈世界，另外四个`inverted/forced0`×mirror/always欺骗反馈世界，总共**274原生世界**。正常世界必须全部真实完成48/48目标才比较完成后的收费，欺骗世界不计真成功。每次反馈只在主体原生Write11之后才经外部真实（或实验指定失真）写入cell20，未来任务序列不会馈送给PID1。不能筛选成功案例、更改源码或后验混合环境权重。

## 验收与失败封存

**主要工程能力门槛**：正常镜像真源PC40与PC173真实参数始终严格对应，原生执行费、16/180/300/6000约束、PC67分支按比较结果进行且双方向真实发生，并在真正重复值的情况下跳过有偿PC28，所有270正常世界48/48真目标完成。独立解释器必须逐行重建**274个世界每条收费CIL、每个程序自变异、细胞40写入、外部真伪反馈、PC、寄存器和余额**，与Rust原生全量JSONL一致，`first_divergence=null`，placebo与mirror全轨迹等价。要报告`matched_noop_candidates`和`state_changes`，不能将从未触发的支路误算有效。

**更强的总效率门槛**：mirror在45条完整新任务的真实收费合计**严格优于同骨架mirror_always且mirror_abstain两臂**。若只优于always而不优于abstain，**净效率假说失败**；即使完全实现镜像能力，仍不能称为已经学会评价修改未来价值。

**失配负控门槛**：研究者按收费屏蔽PC28源码效果后，若镜像仍Write40即会失配；必须记录真实失配事件，并明确禁止称此对照为“修改效果的纯因果消融”。不伪造内核认证、追认演员已掌握原始源码读指令、不引入第二PID，也不以成功任务数掩盖私有算力成本。

**所有正负结果均公开。** 即使C6达到部分技术能力，也不能称为“个体发明自己的算法”“从反馈预测净ROI”“独立认证环境奖励”或者CL1B B3/B4达成。
