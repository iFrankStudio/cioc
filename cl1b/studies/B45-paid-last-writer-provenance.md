# CL-1B B45 — finite, paid, generic last-writer provenance physics

**Protocol frozen 2026-11-16 after independently parsing B42's actual Rust CIL source, before B45 native Rust CI.** These forecasts are NOT native results. CL-1A remains archived. B3/B4 do not become met simply by enabling a new observation primitive.

## Falsifiable question

B44 establishes that two causally different output histories can converge to exactly the same full current World state **after excluding the researcher-only event log**. Can a **generic, identity-neutral, paid and storage-bounded** piece of additional substrate information — a cell's latest native writer identity — allow the same continuing CIL actor to distinguish an external overwrite from one of its own task writes, without granting any privileged fitness or repair decision? What is the price, false-positive boundary and cost-versus-immutable-control?

This study adds a native environmental law, not a new actor-discovered algorithm. No claim of self-originated validation or open-ended evolution is possible from a researcher-authored guard.

## World-law design and ABI

A new **opt-in** `World::with_cell_write_provenance()` creates a `cell_last_writer: BTreeMap<CellKey,i64>` separate from the world's ordinary mutable values. On enabled worlds, every newly allocated shared cell occupies **two shared storage units** (data and last-writer metadata) within the **existing strict total storage cap**. `Intervention::SetCell` records **0 = external**; any successful ordinary CIL `Write` records its **actual positive PID**; ordinary `Delete` frees both units. A rejected allocation cannot consume a hidden metadata slot. The map is serialized with the world so the provenance actually survives snapshots (and differs between the B44 counterfactual histories); it does not make the historic observer event log guest-accessible.

Add **generic opcode tag33**, `Op::ReadLastWriter{dst,address,next}`, conforming to the existing five-cell graph ABI. It consumes **one real native instruction credit** and copies to an ordinary register the last actual writer of the arbitrary cell addressed by another ordinary register. `-1` means unknown/untracked/absent, **0** means the environment, and positive values identify an internal PID. The source is **not** a trust score, task success predicate, cryptographic signature, fitness check or evidence that a specific value was generated by correct code. No actor instruction can write the metadata directly, but anyone can still write the data cell (which updates source honestly).

Default worlds remain **bitwise-compatible in serialized JSON**: new world fields are omitted unless enabled, and previous opcode tags 0–32 retain their meaning. Tracking must begin before any data cell exists, so the world cannot freely backfill erased history. Old CIL `Read` and `Write` retain their prior behavior and charges in disabled worlds. The B31/B34 private ABI and all B00–B44 regressions must be re-run. A new CIL observation requires paid compute even though provenance bookkeeping is performed by generic substrate physics on existing writes; the extra stored metadata consumes finite world capacity. This distinction is an **environmental information affordance**, not an actor self-originated resource purchase.

### Identity and truth limits

- A writer tag identifies **who most recently wrote an address**, not whether the instruction performed useful work. An actor itself can write deceptive data yet have a genuine own-PID tag.
- Last writer does **not** bind an earlier separate value `Read` atomically to a later `ReadLastWriter`: multi-actor scheduling can produce a time-of-check/time-of-use race. B45 does not claim general tamper resistance.
- The map stores only **one** origin per live cell; overwritten earlier history is still lost. This is **not** full append-only historical provenance.
- A compromised code path executing under the same PID would appear as that PID; the sensor does not detect intra-PID malicious/incorrect writes, nor can it infer semantic correctness.

## Exact pre-native experiment matrix

**Four original training values `[-1,0,1,17]` × two unseen nonzero values `[-9,23]` × seven source/environment arms = 56 native worlds.** Each begins with128 local credits, zero shared pool and strict finite storage. The environment replaces input cell7 after64 attempted native instructions; no actor is rescued/restarted/refilled after halting. Actual process-origin output11 writes are scored only after the individual's original input is restored; diagnostic writes are excluded. Rejected writes and failed worlds remain counted.

The **same B42 38-node source** is used as the founder. An investigator-authored optional four-CIL-op guard appends at nodes38–41 and reroutes only the zero-discrepancy branch at PC13 to those instructions:

1. paid `ReadLastWriter` of output11 into register3;
2. paid `Const` of PID1 (comparison target) into register2;
3. paid `Sub` comparing register3 to register2;
4. paid `Branch`: if not the actor's PID, take B42's existing candidate construction path; otherwise continue the existing acceptance path.

The guard is **hand-authored**, not discovered or learned; the real candidate is still produced only by B42's native paid `CloneNode` (now index42) and ordinary `PatchNext`.

Seven arms, 8 worlds each:
- **GuardTrackedSpoof**: provenance enabled, charged CIL guard enabled, externally forged output `train+1` between actual PC10 Write0 and PC11 Read.
- **GuardTrackedGenuine**: same guarded source and tracking, no attack, tests false failures and the zero-diagnostic blind spot.
- **GuardTrackedEcho**: same tracked guard, external write of identical actual value0 at the same time, tests overreaction to provenance without value change.
- **GuardUntrackedSpoof**: same CIL guard but tracking disabled, sensor returns unknown -1. Fail-closed processing may exhaust or halt instead of delivering service.
- **OriginalTrackedSpoof**: last-writer data is available but original **unmodified B42 CIL source does not observe it**; tests whether the new world law alone silently fixes the actor.
- **OriginalUntrackedSpoof**: original unmodified B42 in legacy world with same spoof; baseline from B43.
- **StaticTracked**: immutable four-op correct copier with tracking enabled; no guard, no self-edit, same compute budget.

Additional narrowly scoped native compatibility checks: exact tag33 decoder, two-unit strict storage with delete/reallocation, rejected native Write not partially allocating metadata, back-compatible default JSON decoding, an unrelated PID2's actual writer value2, and **replay of the B44 genuine-versus-forged data-history pair with provenance enabled**, in which the current states now differ by last-writer metadata and one paid guest CIL sensor can distinguish 1 versus0.
