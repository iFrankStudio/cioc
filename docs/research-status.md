# CIOC research status

The project distinguishes topological cycles, causal maintenance, internal functional repair and organizational closure. None alone establishes life.

## Validated toy scenarios and limitations

- V0.1: call cycles versus causal repair, external versus internal interventions, redundant maintenance and resource constraints.
- V0.2: reconstruction of maintenance programs using retained templates.
- V0.3: bounded program synthesis without complete program backup; searcher still fixed.
- V0.4: regulator program reconstruction; scheduling and program contract remain host-provided.
- V0.5: repair decisions driven by organism program graphs; restricted candidate language.
- V0.6: complementary O/G/V/M roles, task and contract reconstruction; critical roles remain single points of failure.
- V0.7: internal reconstruction of G; O/V/M failure and joint failures expose lack of full organizational closure.

## Next question

Can complementary executable roles recover each other's functions, including O, V, and M, without complete backups or a host-level specialized repair controller?

## Methodology

Record every role definition, damage intervention, reserved contract, environment resource rule, exact candidate search bound, internal and external repair event, negative control and test seed. Pre-register evaluation criteria. Run interventions from identical snapshots.
