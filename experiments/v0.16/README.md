# CIOC V0.16 — 资源生态与有限控制器相互维护

这是当前四轮迭代中最综合的候选模型：继承 V0.15 的资源生态、可遗传程序、有限变异与局部适应性重构，再让每个个体携带**两份不同源码但功能重叠**的诊断/重建控制器。其中一份损坏时，另一份可以依据一个前缀片段和有限候选搜索修复它，随后继续修复代谢程序。

运行：`cd experiments/v0.16 && python -m unittest -v && python run.py`。该版本需要保留同级 `v0.15/cioc.py`。

正反对照：主控制器损坏、次控制器损坏、两者同时损坏、禁用互修、移除片段、能量不足、控制器修复后继续修复代谢。

**局限必须保留**：两个控制器是设计者放入系统的功能冗余，不是自然涌现。控制器功能检查、搜寻、授权安装、能量记账、繁殖和调度均由宿主实现。两者同时损坏无法修复；与严格的组织闭合仍有明显距离，也没有从零生成新原语、无界组织创新的证据。V0.16 在资源约束与内生维护的**组合**上比此前更接近目标，但不能宣称已经产生赛博生命。
