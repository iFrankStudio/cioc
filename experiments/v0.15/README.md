# CIOC V0.15 — 资源约束下的局部维护与可遗传策略

将 V0.14 的指令生态与可损伤维护策略结合。每个体携带两条可复制、可变异的程序：代谢/繁殖 `body` 与 `controller=(AUDIT,REBUILD)`。维护程序在代谢效果不足时自行执行有限搜索，以**当前资源收益**而非预先保存的标准源码选出替代代谢程序。

运行：`cd experiments/v0.15 && python -m unittest -v && python run.py`。

需严格区分：`repairs` 计数包含因局部资源耗尽或季节切换而发生的重新配置，**不全是故障修复**。实验者的 `damage_rate` 产生故障，但损坏事件标记不直接传给个体的 `AUDIT`。在单个实验中只统计可观察的修复事件。

**局限**：`AUDIT`、`REBUILD` 两种原语及有限代谢候选枚举、候选收益计算、代码安装，均由宿主实现。若 `controller` 自身损坏，个体不能恢复。初始 `DIVIDE` 锚点是局部保存的信息；不是从零推导。
