# CIOC V0.14 — 原生信息资源生态中的变异与竞争

为避免长期停留在预置维护角色的循环修复，本轮引入独立实验轴：指令序列必须消耗执行能量、争用 A/B 两类有限资源，并通过实际运行 `DIVIDE` 复制。世界只实现解释器、随机调度、资源守恒与存储容量；没有宿主按评分选择个体。

运行：`cd experiments/v0.14 && python -m unittest -v && python run.py`。

可遗传的程序由 `EAT_A` / `EAT_B` / `DIVIDE` / `WAIT` 构成；复制时以种子控制的概率改变一条指令。单个初代个体在 A 资源占优势的阶段扩增，再切换到 B 资源，测量种群存续。每个动作都消耗能量，供给与容量有界。

**解释限制**：变异的操作集、执行与复制语义、资源种类及转换率均是人工提供；不具备维护组织、自发产生的新计算原语、开放式演化及自主确立目标的证据。单次成功须和多随机种子对照一起报告。
