# CIOC V0.13 — 有限多数诊断与对抗证据

研究对象：在同一判据上有三个可损坏、可独立报告的诊断程序时，能否抵御单个反向报告，并识别回放、重复身份、证据不足等问题。

运行：`cd experiments/v0.13 && python -m unittest -v && python run.py`。Python 3.10+，仅标准库。

核心变化：三个诊断程序独立执行有限的 `SENSE`→`REPORT` 指令；必须有至少两个不同注册身份在当前 epoch 给出一致判断。冲突身份弃权，旧 epoch 不计。恢复时还要消耗资源并使用两份局部片段，通过有限挑战选择替代程序。

**严肃限制**：`observed()` 在宿主中用事先设置的有限 canary 契约生成故障信号。故障信息并非从开放环境自主获取。多数机制不能抵御两位串谋或共同故障；它也不是共识协议，不提供强身份防伪及网络异步安全。恢复搜索和验收仍是宿主原语。

`results/experiments.json` 是确定性结果，`test_output.txt` 为实际运行日志。不可将测试通过解释为真实生命诞生。
