# CIOC V0.11 — 运行中语义损伤的组织内诊断

本实验从 V0.10 的“明确删除程序”升级到**程序仍存在但行为已经失效**的情况，检验内部诊断策略能否将目标隔离并触发原有维护链。它是有限机制验证，不代表真实数字生命或完整组织闭合。

## 运行环境

Python 3.10+，标准库。**需要保留同级目录 `experiments/v0.10/cioc.py`**，因为 V0.11 继承该版本的世界模型，不复制或改写旧版本原始源码。

```bash
cd experiments/v0.11
python -m unittest -v
python run.py
```

`run.py` 会生成 `results/experiments.json`。

## 新机制

- 增加可执行诊断策略 `D = (AUDIT, QUARANTINE)`，这是世界中可损坏、可篡改的状态。
- `AUDIT` 使用**宿主提供的有限行为探针**检查 O/G/V/M/PV/PI 是否仍符合预设行为契约；每项检查消耗预算。
- `QUARANTINE` 对存在且已查明异常的程序进行隔离，置为缺失状态；V0.10 维修链随后尝试恢复。
- 无异常和在有限探针下等价的替代程序不得被隔离；保留外部修复独立计数。
- D 损坏、O 损坏、重要角色联合损坏等保持失败作为对照。

## 测试范围

12 项单元测试，17 个场景：单节点语义污染 6 类、等价替代程序 5 类、无诊断、预算不足、D 损坏、顺序损伤、双节点损伤、外部恢复。

## 已知限制

1. 行为期望/探针和成功判据仍由宿主代码指定，**不是组织自己推导出的契约**；`run().healthy()` 是实验测量接口，不参与修复决策。
2. 主机的通用解释器、调度、候选搜索、原子提交均固定；诊断策略 D 也没有内部再生机制。**不能宣称完全内生诊断或组织闭合。**
3. D 的指令语言仍然是两条预设操作，测试仅涵盖离散有限的真/假刺激。不会发现行为探针之外的隐蔽异常。
4. 本实验默认诊断由宿主调度器唤醒。正常情况下主动检测功能虽然基于 D 的可执行代码，却不代表调度本身已经内生。
5. 检测结果仅覆盖人工构造损伤和固定角色粒度，没有考虑测量噪声与开放环境中的误报风险。
