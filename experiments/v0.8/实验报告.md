# CIOC V0.8 实验报告：基于分布式片段的行为等价再生

## 研究问题

如果剩余维护组件并未持有目标生成器完整代码，是否仍能通过有限候选枚举和**行为测试**重建相同功能？候选是否必须与原源码完全一致？

## 实验方法

- 四个角色：观察 O，生成 G，验证 V，修改 M。
- 可执行维护算法以三个指令构成，世界提供有界解释器与资源计量。
- 分散在不同角色的片段仅约束候选第 0、2 个位置；第 1 个位置仍须搜索。
- V 通过有限的正负行为探针对候选评分，不读取或对照原始程序源码。
- 原程序 `('ENUMERATE', 'PROPOSE', 'IDLE')`，可接受的重建程序 `('ENUMERATE', 'PROPOSE_ALT', 'IDLE')`。
- 额外验证恢复后的 G 真实执行替代提案指令（并非仅通过探针）。
- 九组干预，从相同初始状态独立运行，固定计算预算与候选顺序。

## 实测结果

见 `results/experiments.json` 与 `test_output.txt`。本地运行 8 项单元测试均通过。

| 场景 | 结果 | 内部安装 |
|---|---|---:|
| O 损坏 | 未恢复 | 0 |
| G 损坏 | 恢复 | 1 |
| V 损坏 | 未恢复 | 0 |
| M 损坏 | 未恢复 | 0 |
| G、M 同时损坏 | 未恢复 | 0 |
| G、V 同时损坏 | 未恢复 | 0 |
| 低预算 | 未恢复 | 0 |
| 必要片段缺失 | 未恢复 | 0 |
| 外部恢复 | 恢复（外部） | 0 |

在 G 单独损坏条件下，搜索四次片段兼容候选，并通过行为探针恢复替代指令实现。

## 解释

实验展示一个较窄的结果：**在受限指令语言、预设片段和有限行为判据下，内部维护链能够重建不完全同源的功能程序。**

该模型尚不能说明全角色相互维持：O/V/M 的丢失仍造成无恢复。片段来自实验者初始装配，且测试裁判属于宿主提供功能。还必须研究行为判据的内生形成、验证器可再生与联合损坏后的组织重构。
